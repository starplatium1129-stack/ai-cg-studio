## 已完成的体验修复

1. **复制统一兼容处理。** 色彩情绪、剧本、作品册、场景/蓝图 JSON 和控制面板原来直接访问 navigator.clipboard，API 不存在时会同步抛错；部分入口没有任何反馈。现在优先系统复制，失败后尝试浏览器选择复制；仍失败则明确提示手动复制。临时文本框留在当前弹层内，完成后清理并还原焦点；不读取剪贴板。成功提示只在复制成功后出现。
2. **作品册批量操作可恢复。** 切换搜索、收藏或项目筛选后清空原选择，避免把已隐藏作品带入批量删除；部分失败后保留失败作品的勾选，可直接重试。回收站及 30 天恢复规则保持原样。
3. **蓝图连续复制不串记录。** 副本依次使用 _copy、_copy_2、_copy_3 等可用 ID，避免同一源连续复制时 ID 重复、编辑定位到另一条。只改变草稿副本 ID 分配，没有保存或修改任何蓝图内容。
4. **页面加载失败有恢复入口。** 动态页面文件加载失败时显示持续可见的提示，可重新打开目标页面、继续当前页面或返回首页；不自动刷新用户页面。故障注入验证了恢复后正确进入目标页。
5. **控制面板保存有进度反馈。** 配置提交期间按钮显示“正在保存…”，拦截重复点击/回车；成功或失败后恢复可操作状态。测试通过模拟服务验证，没有写入真实服务配置。
