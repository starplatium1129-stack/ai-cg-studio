路线图原则：稳定底座已经完成，后续以真实创作收益驱动。

新增功能必须至少改善一种结果：更容易找到场景、更快得到满意画面、更稳定地保存作品、更一致地呈现角色，或更容易诊断服务。只增加页面、依赖和设置项而不改善这些结果的功能不进入开发。

BASE

稳定创作底座

从场景维护、导演出图到作品欣赏、语音和服务控制，已经形成完整本地闭环。

已完成
  • 场景、标签、精选层级和样张无代码维护
  • 事务备份、原子写入、校验失败自动回滚
  • 横竖图原比例展墙和沉浸式作品观赏
  • 控制面板健康检查、进度状态和 GPU 操作互斥
  • 固定声线参考、确定性采样和逐句完整语音
  • TypeScript 契约、单元测试、浏览器回归和 CI
PHASE 1

可靠性精修

不扩张产品边界，优先消除剩余数据丢失、浏览器兼容、诊断和安全隐患。

下一阶段
P0 · 存储

作品库存储体检

已完成：IndexedDB 容量预警、损坏记录隔离、存储体检入口；完整作品包导入导出沿用现有备份格式。

P0 · 诊断

一键导出诊断包

已完成：控制面板汇总服务版本、端口、健康状态、脱敏配置与日志尾部。

P1 · 安全

移除 HTML 事件属性

已完成：中页与导演台均改为 data-action 委托；script CSP 默认 self，仅聊天页保留 unsafe-eval（Live2D）。

P1 · 类型

渐进迁移高风险模块

运行时服务已迁齐：`control-operation`、`serial-queue`、`http-client`、`tts-service`、`ollama-service`、`translation-service`、`live2d-service`（TS + emit + 单测）。`tools/` 控制器仍按需渐进，不整库重写。

P1 · 语音

真实声线基线

已完成：宁宁/夏目固定台词矩阵、golden metrics、leading/trailing silence 与基线对比；离线进 validate，live 捕获 opt-in。

P2 · 兼容

无障碍与设备矩阵

已完成：首页/导演台/作品册/控制台 skip+main；作品册观画 focus trap 与焦点回归；Playwright 覆盖窄桌面、平板、手机视口 smoke。

进入下一阶段的标准：连续使用中没有数据丢失；完整备份可恢复；控制面板问题可通过诊断包定位；浏览器回归、性能预算和 CI 持续通过。
PHASE 2

创作体验增强

在不遮挡画面的前提下，让比较、整理和继续创作更自然。

可靠性完成后
作品册

私人展览与画册

按项目、角色、季节或自定义主题组成展览，提供安静的全屏播放；默认仍先看作品，不把参数铺在画面上。

比较

同 Seed 版本对照

并排或滑杆比较两张作品，显示真正变化的 Prompt 与参数，帮助判断 LoRA、构图和光照调整是否有效。

分支

作品变体树

从满意作品继续微调，记录父作品、Seed 和变化原因，避免历史记录变成无法理解的平铺列表。

项目

可移植创作包

导出一个项目的故事、场景、Prompt、参数、语音和作品原图；导入时预览冲突并允许合并。

发现

本地偏好推荐解释

继续使用本机收藏和评分改善场景排序，同时说明“为什么推荐”，并提供一键关闭或重置。

语音

台词与音频工作流

让场景台词、角色、字幕和生成音频保持对应，支持单句重做与整段导出，不引入复杂时间轴编辑器。

完成标准：新能力必须减少重复操作或提高作品选择质量；作品展示仍保持原比例、低干扰和键盘可用；旧项目无迁移损失。
PHASE 3

内容与工作流扩展

只有实际需要第三个角色、新工作流或批量迁移时才启动，避免提前泛化。

按真实需求
角色

配置驱动的新角色接入

通过角色资料、LoRA、语音、立绘和校验清单注册角色，自动生成筛选项；角色独有提示词仍需人工审核。

场景

场景包导入导出

把场景数据、标签、精选信息和审核样张打成可验证的内容包，支持预览、冲突检测与回滚。

工作流

ComfyUI 工作流导出

将当前导演参数映射为版本化 workflow JSON；先支持常用单人路径，再评估双人区域控制。

参考图

色彩、光照和构图辅助

从用户主动选择的参考图提取画面方向，只生成可检查的建议，不自动覆盖角色 DNA 或故事内容。

训练

素材与标签导出

按角色、服装和身份锚点导出本地训练清单，保留来源与审核状态，不在网站内承担完整训练平台。

控制

可选参考图管线

针对明确场景评估 IP-Adapter、ControlNet 或区域提示，能力不可用时必须无损回退到现有出图链路。

启动条件：至少存在一个真实内容包、第三角色或 ComfyUI 工作流需求；先制作最小试点，通过身份、构图和维护成本评审后再进入主流程。
RESEARCH

长期研究方向

可以做原型，但不承诺进入正式产品；必须证明比现有简单流程更好。

不设期限
故事

本地故事润色助手

只在用户请求时提供角色一致性、动作可画性和镜头建议，保留原文并能逐项接受或拒绝。

分镜

多画面故事板

把一段故事拆成少量连续 CG，并锁定角色身份、服装和时间线；先解决一致性，再考虑批量生成。

质量

可解释的候选图比较

结合固定 Seed、人工评分和身份锚点生成对照报告，辅助挑图，不让自动分数替代逐张观察。

性能

闲时预热与资源预测

根据设备和当前模式建议加载顺序；不得未经允许常驻占用显存，也不得后台自动开始生成。

衡量是否真的变好

可靠性

保存失败不丢数据；备份可恢复；损坏记录不拖垮整个作品库；所有写入都有明确结果。

创作效率

从故事到首次出图的操作减少；重新找到满意配置更快；重复输入和手工文件操作继续下降。

画面体验

横图、竖图和方图始终完整呈现；画面优先于参数；新增功能不让导演台和作品册变成仪表盘。

角色一致性

脸、发型、瞳色、装饰、服装、双人特征和声音身份有稳定基线，变化能够被发现和解释。

性能

关键页面继续满足请求数、脚本体积和传输预算；离开页面后释放 Blob URL、音频和服务资源。

维护成本

普通内容更新不改代码；结构变更有契约、迁移和测试；不为一个功能复制第二套状态与存储逻辑。

产品边界

可以考虑

  • 本地优先、可导出、可恢复的个人创作能力
  • 能提高角色身份、构图和故事表现的辅助工具
  • 按真实需求增加角色、场景包和生成工作流
  • 让朋友安全查看或临时体验的轻量分享

暂不计划

  • 公开注册、社交关系、社区投稿和公开作品流
  • Scene 商店、订阅、支付或商业化运营后台
  • 长期托管的云端图库、云端生成和用户数据平台
  • 为了技术潮流重写为大型前端框架或拆成微服务
  • 无人审核的自动发布、自动训练和自动替换模型
执行节奏

一次只推进一个主要能力：先写清用户问题和完成标准，再做最小版本，补数据迁移与测试，真实使用一段时间后决定继续、调整或删除。路线图不是功能承诺清单，任何项目都可以因为收益不足而取消。
