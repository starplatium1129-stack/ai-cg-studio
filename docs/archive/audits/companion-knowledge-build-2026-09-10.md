# 角色记忆、桌宠行为、参考卡与桌面打包

日期：2026-09-10。范围来自用户指定的前三个专项：角色知识/长期记忆、桌宠行为、分镜参考卡；同时优化桌宠窗口布局并补齐本机桌面打包能力。

## 功能修复

### 角色知识与长期记忆

- 角色设定加载失败后允许重试，后续消息会重新预热缺失档案；并发刷新只发布最新请求的结果。
- 长背景保留至 4,000 字并按短条目召回，避免前 240 字之外的设定永远无法命中；召回数量在空查询、无命中和正常查询时均遵守限制。
- 支持现有档案中的字符串身份描述，保持角色 ID 精确隔离。档案仍来自 data/characters.json，没有新增或编造设定。
- 记忆按最新版本去重，同 ID 和同来源消息更新不会把旧文本再次并入；编辑为相同文本时合并重复项，非法角色标记不会转成宁宁记忆。
- 每次修改读取当前持久化状态，写入成功后才发布本地快照及成功提示；失败保留原有记忆，损坏存储不被悄悄覆盖。其他窗口清空存储时同步清除旧显示。
- 全量字段核对：160 份档案均有背景、性格、说话风格和身份字段；6 份喜好为空（shiina_mashiro、izumi_sagiri、takarada_rikka、hayasaka_ai、arima_kana、hori_kyouko），本轮未虚构填补。不同来源的语义冲突仍由用户编辑/删除，不宣称自动判断哪条事实为真。

### 桌宠行为与好感度

- 勿扰、主动行为关闭和安静时段统一控制提醒出队与显示；切换角色清除上一角色的待展示台词。
- 被勿扰抑制的问候不消耗本时间片机会，日期进入问候键，跨日可再次问候；过期提醒不在恢复后集中弹出。
- 隐藏窗口或静默状态停止事件请求；图片计数失败不会归零制造“新图入库”，同类服务事件合并，迟到的旧角色请求不生成新角色通知。
- 行为配置跨窗口实时同步，独立聊天窗随时间更新安静时段与语音门控。
- 好感度过滤无效数值，修改前读取最新记录；存储损坏或写入失败不假装加分，互动加分返回实际增量。

### 分镜参考卡

- 每张卡片持有可取消请求；换角色、换服装、移除卡片与卸载时，旧响应不能回填到当前卡片。
- 每张图片独立失败处理，其余参考图继续装配；pending 不计入成功，缺图明确报告。显式不存在的服装不静默替换成默认服装。
- 手动上传检查图片类型、大小与并发槽位，自动/手动回填都限制四张图片；卸载释放预览 URL。
- 删除卡片同步重排镜头中的角色编号；清空自动身份描述时保留用户手写文本。异步结束不覆盖用户在等待期间改写的身份文本。
- 参考卡或首帧准备中阻止整批提交，避免生成请求读取一半素材。

## 桌宠布局与输入

实际截图确认了 360px 角色小窗按钮折行、浅色工具栏底色不协调，以及浮层文字继承全局颜色的问题。本轮固定工具栏操作区宽度、角色按钮不换行、长房间标记省略；调整设置弹层可用高度与滚动行为。

独立聊天窗提高输入字号，长输入按窗口高度展开，删除重复的未就绪状态行；中文输入法确认回车不会发送。状态广播不重置当前草稿，角色切换按原角色保存草稿；桥接发送失败保留文本并允许重试。

深浅主题均检查选中角色按钮及问候气泡对比度，气泡测试按纯白背景进行最不利合成；深色艺术浮层的正文、加载提示与状态文字使用对应的艺术表面文字令牌。样式动效豁免从 4 降为 3。

## 本机打包能力

本机已有 Visual Studio C++ 与 Windows SDK，本轮安装 Rust MSVC stable 工具链，并从官方源取得项目所需 Cubism SDK for Native R5。SDK 位于 runtime/desktop-build-sdk/CubismSdkForNative-5-r.5，未进入 Git；工具链位于用户目录。

- `npm run wf -- desktop:doctor --json`：只读检查 Windows x64、Node、Rust MSVC、C++、Windows SDK 与完整 Cubism SDK。
- `npm run package:tauri`：现有入口增加前置检查和自动路径发现，显式 SDK 配置错误时立即失败。
- `npm run wf -- desktop:package-local`：同一构建链路，本地配置跳过压缩以减少验证等待；默认入口仍使用 LZMA。
- 原生 build.rs 支持本地 SDK 目录，保留历史路径兼容；SDK、编译缓存和安装包均不提交 Git。

依赖来源与安装方法见[桌面部署说明](../../desktop-deployment.md)，沿用既有部署入口，没有另建部署脚本。
