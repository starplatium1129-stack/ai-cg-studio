## 已修复的实际问题

- **SD 长任务中断**：代理的 15 秒 `timeout` 实际限制客户端整段连接，并在 keep-alive 轮询上累积监听器。改为仅计时上游 TCP 建连，保留 20 分钟生图等待。真实隔离 HTTP 上游延迟 15.5 秒仍返回图像；连续轮询监听器不增长。
- **本机控制被外站触发**：外站表单曾能向本机 `/api/start` 写配置。共享本机授权补 Origin、Fetch Metadata 和代理头检查，保留桌面、本机开发跨端口和命令行入口。隔离配置上的复现从 200 变为拒绝。
- **隧道 WebSocket 误拒绝**：升级路径错误地把完整 URL 与 Host 比较，现在与 HTTP 共用解析；实际 101 握手及错误域名、凭据回归通过。
- **取消刷新污染新请求**：关键浏览器回归暴露 Anima 角色切换后“底模未发现”且不发出生成请求。公共 API GET 去重误复用尚未清理的已取消 Promise；现在新刷新跳过已取消传输，旧请求只清理自己的登记。纯客户端回归在旧实现确定性失败，新实现通过；原 Anima 浏览器用例不改等待时间也通过。既有共享请求首发者取消会影响已搭车者的行为保留，没有宣称所有消费者完全独立。
- **错误的本机判断与成人卡展示**：去除 `hostname.includes('tauri')` 和可注入桌面对象授予本机权限的逻辑，只认精确 loopback/桌面来源。热门场景页按来源控制成人内容，未知公网域名实际无成人卡、无成人图片请求。
- **回收站与历史记录**：软删/撤销的历史、项目引用、回收站用同一 KV 事务提交；自定义存储失败时补偿回滚，包括无 remove 的适配器。修复删除后迟到读取复活记录、空项目列表复活旧项目、清库后历史残留和作品 ID 碰撞。
- **配音生命周期**：二进制合成接入 `voiceApi.synthesize`，支持超时与取消；卸载后不再新建音频 URL 或弹出成功提示，生成参数和下载名固定为点击时内容，迟到译文不覆盖新字幕。
- **未审核图片被自动通过**：人工审核汇总工具改为每张图必须有明确决定和对应 `recordId`；缺失决定保持 pending，旧图审核不能转移到重试图。入口要求显式指定本轮清单与决定文件。
- **可读性与筛选**：修复实际渲染的分类计数 opacity、成人分类悬停背景对比度，删除三处无效旧样式；将历史 SFW 值按 All 展示和筛选。浏览器对比度工具计算文字 alpha 与祖先 opacity，覆盖带元素子节点的文字标签。
- **维护与启动**：6 个可复用工具补登记，11 个固定批次实验移入被忽略的 `scripts/archive/`，本地副本保留；零引用检查接入 check/CI 并覆盖桌面源码引用。安装依赖不再覆盖自定义 Git hooks，只清理指向已移除目录的旧配置。扩充已有 STARTUP，纠正直接静态托管 Vite 源码的错误启动建议。
- **重复提示词装配**：工作台复用 `unified.studio` 的同源字段，去除重复 computed 链；没有改变提示词规则、场景数据或生成参数。
- **绘图路由预算**：新增可靠性修复后一度超出 140 KiB 预算 105 字节。将换装上传/提交动作改为点击确认后动态加载，路由降至 141,940 字节（138.6 KiB），剩余 1,420 字节；2,670 字节的动作块不在路由静态闭包。公共 API 修复后入口闭包为 359.2 KiB。原换装操作实现与 HEAD 逐句比对一致，预算未放宽，余量仍较薄。
