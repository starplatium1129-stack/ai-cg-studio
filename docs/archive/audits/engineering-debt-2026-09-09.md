# 办公机工程债务治理（2026-09-09）

范围：页面职责拆分、体量豁免清理、关键行为测试、任务恢复与保存失败处理。用户明确将参考图交给后续主力机；本轮不补图、不修改角色/场景数据、不部署桌面程序。

## 已实现

- 绘图、作品册、场景维护、场景探索、视频、桌宠与分镜编辑器的状态编排迁入对应 composable。作品册另分离存储、回收站、导出与写操作；绘图另分离生命周期、结果元数据、生成操作与蓝图恢复。样式仍由所属视图加载。
- 后端分离聊天消息校验、维护备份/输入校验、视频流输出与视频 AI 配置/输出校验。原路由入口、授权中间件和响应契约保留。
- 词典按内容分片，提示词类型与诊断职责分离；原公开导出保留。与修改前版本对照，词典值相同，302 个场景、三种引擎的 17,214 次提示词函数输出比较一致。本项不是出图验收。
- 所有受体量门禁检查的文件均不超过 600 有效行，历史豁免从 17 项清至 0 项。没有抬高限制或新增豁免。
- 任务摘要首读失败可重试，读取失败不会覆盖未读出的历史。后端任务身份用于重连去重；视频与分镜记录支持查询真实状态和取消，并返回对应任务链接。查询失败不伪报完成、不自动重发，旧响应不能覆盖更新后的状态，卸载时中止在途查询。
- 作品收藏按作品 ID 串行写入，连续点击保留最新意图；最后一次失败回退到最近确认值。单张删除成功后才更新界面，并保留删除期间新加入的作品。
- 全库前端覆盖率门槛由行 5% / 分支 3% 提升为 17% / 11%；store 为 60% / 40%，utils 为 29% / 22%，config 为 39% / 17%；任务中心单文件为 90% / 70%。这些是门槛，不等于系统整体被测试的比例。
- 修正重构后仍绑定旧文件位置的架构检查；浏览器检查按实际保存入口数量验证忙碌状态，并通过可见的“对话设置”入口打开聊天配置。

## 本轮验证与边界

- 办公机结构模式 `gate:full --all` 通过：21 步综合检查、前端测试、431 项 Node 单元用例、25 组接口契约、生产构建及打包预算。默认素材文件模式仍需主力机复验。
- 前端覆盖率运行通过：52 个测试文件、416 个用例；本轮行覆盖率 18.46%、分支 12.82%。这不包括 Node 与浏览器测试覆盖。
- 前端行为测试覆盖存储失败重试、任务重连去重、旧响应乱序、取消确认、卸载释放与连续收藏写入；角色快速切换和资源失败恢复继续由现有 sceneStore 测试覆盖。
- 新增双主题浏览器测试：恢复已保存视频任务、查询原任务 ID、取消后确认状态、没有重复提交；任务中心截图已人工查看。
- 宽屏 17 页面 × 两种主题的 34 项布局检查通过。完整关键浏览器矩阵首轮 269 项通过；修正链接精确匹配与移动控制台的旧样式断言后，剩余 4 项定向复验全部通过（包括此前浏览器关闭超时的备份用例）。
- 追加缓存视频页切换后，任务恢复、取消、缓存页选择另一任务与批量任务跨页保留共 6 项定向检查通过。关键浏览器套件现为 274 项，本轮通过结果由完整矩阵及定向复验共同覆盖，并非宣称最后一次整套运行全绿。
- 办公机沿用 CI 的 `AICS_REFERENCE_AUDIT_MODE=structure`：校验参考索引结构，明确不检查素材文件存在性。默认文件核验曾实际执行，报告本机未配置参考素材根目录、2,534 条已登记 URL 无法在本机核验；未通过改写索引或 pending 掩盖。
- 不包含主力机真实出图、参考素材逐图审核、真实语音设备或原生桌宠验收。页面内批量调度仍不会在刷新后自动重发；无后端任务 ID 的旧记录保持“待检查”。

一次性迁移、对照与检查日志留在被忽略的 `scripts/archive/`，截图在被忽略的 `.review-shots/`。可复跑入口使用 `npm run workflow -- gate:full`、`npm run test:frontend -- --coverage` 和 `npm run test:e2e:critical:run`；主力机不设置结构模式时继续执行素材文件核验。
