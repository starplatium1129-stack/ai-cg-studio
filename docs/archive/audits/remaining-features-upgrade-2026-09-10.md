# 剩余功能升级与全站回归

日期：2026-09-10。本轮沿用前两轮聊天、视频素材及作品导出修复，继续处理备份、存储维护、分镜 AI、批量任务、场景保存和通用下载。用户要求覆盖项目剩余功能；本报告区分代码已修复、浏览器已验证与本机无法进行的真实服务验收，不把页面可打开当作模型能力交付。

## 功能改进

### 备份与存储

- 恢复前完整校验记录列表和图片列表；无效、重复图片 ID 或损坏记录不再静默跳过。
- 先解码全部图片，再以新 ID 暂存；统一重映射作品/项目中的图片引用，防止合并时同 ID 图片覆盖现有作品。
- 作品历史和项目使用同一个 IndexedDB 事务发布。图片暂存或记录发布失败时清理新图片、补偿设置；现有作品和原图不删除。设置回滚或暂存清理失败单独报告。
- 覆盖恢复替换作品/项目记录，旧原图保留供确认后清理，避免先清空图库再恢复的风险。此策略会暂时增加存储占用；空间不足明确失败，不通过删除旧图腾空间。
- 备份文件读取有版本标记，防止旧读取覆盖新文件；选择超大文件立即清空旧候选。导出遇到图片读取失败不再生成看似完整的备份；appVersion 从实际包版本读取。
- 清理引用范围扩展到作品、项目、回收站、隔离记录、当前标签页的视频/分镜草稿和临时成片。草稿无法解析时停止清理。浏览器 sessionStorage 不能读取其他标签页，所以实际清理仍要求先关闭其他创作标签页。

### 视频与分镜

- 批量重试冻结批次 ID 和失败镜头列表，拦截重复点击；部分重试失败仍恢复轮询，取消后不继续剩余重试。
- 迟到的重试、取消、拼接和轮询响应不覆盖新批次。重连仅在 404/410 时判定任务丢失，暂时断网保留恢复记录。非法 seed 不再悄悄按随机种子提交。
- AI 整理在状态查询期间也锁定，避免双击并发；按原镜头对象应用结果，用户中途编辑或重排时不把迟到结果套到另一镜。
- AI 撤销只恢复其负责的文本字段，保留当前首帧资源；不再撤销文字却释放仍要显示的图片 URL。
- 质量检查的 prompt 建议写入 prompt，不再误写进对白；旧镜头的检查/台词建议不应用到重排后的其他镜头。脚本生成期间检测编辑变化，保留新编辑。
- 一键首帧接入任务中心停止操作；取消后停止后续镜头，并请求终止当前已知后端任务。离开组件释放轮询，服务端取消状态立即结束等待；结果图 HTTP 失败不上传错误页面。若后端终止未确认，停止后续生成并报告。

### 编辑、归档与下载

- 场景保存发送独立快照；保存期间的新编辑继续保留脏标记，并提示再次保存。维护工具与保存互斥，桌面只读模式不发起写入。
- 统一备份、场景维护快照、蓝图、聊天归档和诊断包下载，挂载下载节点并延迟释放资源，避免浏览器尚未读取文件就撤销 URL。
- 聊天归档文件读取失败有可见反馈；批量图片导出报告失败数量。

- 新增定向前端回归 24 项通过，覆盖图片暂存/记录发布故障、合并冲突、候选文件读取竞争、引用保护、下载资源释放、分镜 AI/重试/取消及保存快照。
- 结构模式 gate:full 通过：21 步检查、前端测试、434 个 unit 用例、25 个接口契约文件、生产构建及预算。
- 过程中补齐了测试 fixture 的必填字段与 severity 枚举；通用下载接入控制模块后修正为兼容 Node 原生 TS 测试的相对导入，重跑对应测试和完整门禁通过。
- 新增浏览器故障注入：在第二个元数据写入时模拟配额失败，验证同事务的作品历史回滚、原图字节不变、主题设置补偿及恢复弹层可重试。使用隔离浏览器数据，不操作真实作品。
- 全站关键浏览器回归覆盖 284 项：281 项首轮通过；首页标语仍断言旧版文案、两项备份故障用例未在当前 IndexedDB 准备初始作品，修正测试后这 3 项定向复验全部通过。没有省略首轮失败，也没有把复验称为另一轮 284 项全量运行。
- 覆盖全部 17 个主要页面的深浅主题和 1440/768/390 布局，另含桌面/平板/手机导航、对比度、绘图/聊天/语音/备份/场景保存模拟流程。备份失败后的双主题截图已人工查看，提示及重试按钮可读可用。

## 本机边界与剩余验收

本轮直接查询本机服务：视频、Anima、聊天和 TTS 均离线；视频与 Anima 模型目录报告不可用。没有下载或安装新模型，没有真实出图/出片、真实语音/Live2D 设备验收、桌面安装或 UAC 操作。参考素材未在当前机配置，本轮使用 AICS_REFERENCE_AUDIT_MODE=structure，不代表参考图文件验证通过。

跨 IndexedDB 与 localStorage 无浏览器原生联合事务：本轮保证图片先暂存、作品与项目原子发布，并在可捕获错误时补偿设置；不宣称进程崩溃时所有存储同时回滚。崩溃可能留下未引用的新图片，但旧原图保留，可后续安全清理。

代码修复与模拟验证不等于全模型/全设备质量验收。真实生成效果、素材库补齐、桌宠原生命令终止及规划中的新模型接入继续按 roadmap 管理。
