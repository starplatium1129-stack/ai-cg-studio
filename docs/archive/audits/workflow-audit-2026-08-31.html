八、协作者规则建议（写入 AGENTS.md + workflow.md）

红线：优先复用现成工作流，禁止造简陋轮子。做任何事务前，协作者必须：

  1. 先查：跑 npm run workflow -- --help 或读 docs/workflow.md，判断是否有现成工作流覆盖该事务
  2. 再查脚本：若无 workflow 入口，跑 npm run workflow -- audit:orphans --json 或 grep scripts/maintenance/，判断是否已有现成脚本
  3. 复用优先：有现成工作流/脚本则用之，哪怕需补参数；禁止因"不熟"而另写简陋脚本
  4. 新增需评审：确需新增脚本时，须同时登记到 scripts/workflow.js 的 WORKFLOWS + docs/workflow.md 分组 + docs/INDEX.md（如涉及新文档），三处缺一视为未完成交付
  5. 一次性脚本归档：用完的一次性脚本及时移入 scripts/archive/（gitignored，git 历史可取回），避免堆积成孤儿（audit:orphans 会捕获）
