# 工程治理后的六维补充审计（2026-09-09）

本轮在办公机执行，承接工程债务治理。以下维度此前已有局部检查，本轮补查并发、缓存页面、嵌套弹窗、同任务重试和供应链失败处理；不把历史 PASS 当作本次结果。

## 维度、发现与优化

| 维度 | 本轮发现 | 实施结果 |
| --- | --- | --- |
| 安全与隐私 | 聊天/视频的配置缓存只比较时间和大小，不比较文件路径；等长、同时间的不同配置可串用 | 两处复用 `server/chat-host-config.js`；按绝对文件路径与文件元数据隔离，返回副本，缓存最多保留 16 项。原路由本机授权与公开响应脱敏保持 |
| 数据可靠性 | 配置原地写入存在中断损坏风险；删除错误曾被当成成功；作品册旧读取可覆盖新刷新 | 配置使用同目录独占临时文件、同步落盘与原子替换，失败保留旧文件；仅忽略删除时文件不存在的错误。作品册按读取代次更新数据、错误和加载状态 |
| 性能与资源 | 显现效果扫描整份文档，缓存页面离开后仍观察变化；作品册首次挂载与激活重复读库 | 显现效果限定在所属页面，停用时断开观察者、取消待执行帧，恢复时重新观察未显示元素。作品册首载只读一次，卸载后停止图片等待队列 |
| 可访问性 | 多个弹窗同时响应 Escape；关闭一个弹窗会移除其他弹窗的滚动锁；初始打开的空弹窗无焦点落点 | 仅顶层焦点陷阱处理键盘，滚动锁按所有者释放；空弹窗可聚焦并还原打开者；缓存页面停用时释放陷阱，恢复后重新接管 |
| 失败恢复 | 后端任务查询失败后，保持同一任务地址不能触发重试 | `useBackendSelection` 暴露重试，同任务在途请求合并，旧请求和已销毁作用域不回写；视频页现有“重新检测”同时重试任务状态 |
| 发布与供应链 | 完整依赖审计的失败被 `|| true` 忽略，缺少可下载证据 | 高危/致命告警阻断完整依赖树检查；运行时检查失败后仍生成完整审计 JSON，并上传保存 14 天 |

## 复现与验证

- 修改前新增回归实际复现四个问题：跨路径配置缓存串用、作品册旧数据回写、显现效果观察其他页面、嵌套弹窗错误处理 Escape。日志在本机被忽略的 `scripts/archive/dimensions-red.log`。

- 前端类型检查通过；前端 54 个测试文件、423 个用例通过；安全边界 11 项检查通过。结构模式完整门禁包含 21 步综合检查、434 项 Node 单元用例、25 组接口契约及生产构建。没有修改角色、服装、场景数据或模型编译参数。
- 完整关键浏览器回归 **276 / 276 通过**。包含同任务原地重试、3,000 条隔离作品记录的首屏 60 项渲染与全库搜索，以及双主题、多尺寸、键盘、备份与创作流程。深浅主题的对比弹窗截图已人工查看。
- 体量门禁保持零豁免。最终抽取作品册的角色名称格式化职责后，作品册、对比挑选与跨页任务的定向浏览器复验 **7 / 7 通过**。
- 本轮检查不等同于长期内存压测、完整渗透测试或所有设备兼容性认证；这里报告的是上述具体覆盖。

## 供应链剩余项

本次 `npm audit --json` 返回 **2 条中危、0 条高危、0 条致命**。两条来自同一个 `adm-zip` 解压目标符号链接问题及其上游依赖 `onnxruntime-node`，不是两个独立漏洞。[GitHub 已审核公告](https://github.com/advisories/GHSA-vwc7-r8mq-g2x9)当前列出的已修复版本为 None。

本机依赖为 `onnxruntime-node@1.29.0 → adm-zip@0.6.0`。代码检查定位到 ONNX 安装脚本 `script/install-utils.js` 的解压调用，未在项目业务路由中发现调用。攻击前提涉及解压目录中的本地符号链接；不能据此声称依赖安全或没有风险。npm 提议的自动修复会降级 ONNX，本轮未执行强制降级、依赖替换或安装器补丁。后续在上游发布兼容修复版后复验安装与推理功能，再升级。
