## 提交基线

开始本轮前，已按要求将此前的桌面 UX、样张接入、立绘替换和系列归并提交为 7cc0e3c。

## 粒子同步

- 重新生成加藤惠、椎名真昼、千反田爱瑠、一色彩羽、雪之下阳乃、山田杏奈、和栗薰子的点云。
- 每份点云记录 sourceSha256，测试与对应立绘文件指纹核对，避免后续换图漏更新粒子。
- 亮色画布使用原始调色板、正常混合、不透明主点；对与纸面反差不足 3:1 的颜色增加细轮廓，保留颜色中心，同时适度增加网点覆盖面积。
- 不通过全页面反色或滤镜修改 CG 原图。

## 亮色主题

- 顶栏和控制面板支持深浅主题切换，保存选择，并同步同源窗口。
- 页面、浮层、输入框、禁用文字、功能色、角色强调色、画面衬底及桌面标题栏分别适配。
- 启动引导脚本先于应用载入主题，避免亮色偏好在加载画面中闪回深色。
- 角色强调色保留色相，在浅背景上转换为更深的文字与操作颜色；图片上的遮罩和文字独立于页面主题。

## 页面结构与交互

| 页面 | 改动 |
| --- | --- |
| 角色档案、角色场景 | 左侧统一目录，支持名字/作品/别名检索、系列下拉筛选、键盘选择和定位当前角色；右侧保留当前资料或场景，取消满页系列与角色按钮堆叠 |
| 绘图页角色选择 | 复用同一目录，保留原角色/服装选择回调，限制目录高度，让服装选项更容易到达 |
| 剧本 | 左侧剧本始终可见，右侧显示当前分幕；切换剧本不必返回列表 |
| 画风、色彩、模型、剧本 | 增加资料区直接导航；模型支持搜索，长说明按需展开 |
| 灵感场景 | 缩短顶部展示区域，让搜索和实际场景更早出现 |
| 视频 | 增加镜头描述、画幅时长、任务状态的工作区跳转 |
| 聊天 | 桌面窗口内固定可用聊天高度，输入区保持可见，消息区域内部滚动 |
| 场景管理 | 概况统计默认收起，保存操作保持可达，表格内部滚动，补齐筛选控件的可访问名称 |
| 控制面板 | 调整侧栏品牌排版，修正亮色下状态透明度导致的低对比度 |

## 后端问题与修复

1. 预压缩中间件原先仅用正则检查 br/gzip，忽略 q=0、优先级和缺失压缩格式。现按请求质量权重选择实际可用的压缩文件，并保留已有 Vary。
2. 原先可能返回比原文件旧的压缩产物，或在原文件删除后继续返回残留压缩文件。现异步检查原文件及变体的新旧关系，失效时回退原文件路径。
3. 压缩路径补齐隐藏文件限制、配置的 assets 根目录，以及可变参考索引的 no-cache 策略。
4. 本地健康探测和 ComfyUI 缓冲请求合并为共享传输层，统一处理响应中断、响应体上限和整次请求截止时间。
5. 持续滴流不再无限延长请求，断流会明确失败并释放缓冲；保留现有 ComfyUI 错误分类与非 2xx 处理语义。流式聊天传输不在此次替换范围内。

## 验证与边界

- 262 项前端单元测试、25 项桌面浏览器回归通过。
- 压缩协商/失效、断流/慢速响应测试通过；既有网关、Anima、视频和图片反推路由测试通过。
- 类型检查、生产构建和路由体积预算通过。手动检查了角色、绘图、画册、聊天、模型、剧本和控制面板的深浅主题。
- 本机无完整生成与桌面打包环境，未执行真实模型生图或修改已安装桌面程序；主力机后续打包需纳入这些源码、粒子和主题资源。
