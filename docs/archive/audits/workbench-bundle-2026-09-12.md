## 修改内容

素材分类和专家设置页签改为首次访问才挂载，访问后保留实例，切换不丢场景搜索、画师搜索和手动词条输入。场景模式仍加载其实际可用的生成、提示词和任务功能；隐藏的画面设置等待进入专家页签后加载。

从工作台视图拆出生成、画面、提示词、任务、场景与结果弹窗六个异步展示组件。它们共享原有 `usePromptWorkspace` 返回的状态与操作，没有创建第二套工作区或生成任务。对比、局部重绘、语音、批量和队列沿用原有功能与生命周期，首次使用才请求相应分片。

场景列表、生成设置和任务区样式随所属组件加载；保留 `.pb` 根选择器。移除已无使用方的旧词条、旧快捷创建等样式，以及重复但未消费的词条目录派生状态。角色选项、故事示例和角色键判断从较大的词条目录中独立，实际词条目录、提示词内容与定稿资产未改动。

## 本机性能样本

复用现有性能入口，单 worker、隔离生产服务，每个版本测三次新浏览器上下文的冷进入与随后热进入，表中为中位数。进入指标观察生成条和素材导航，首次操作打开“描述”页签。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 冷进入 | 895 ms | 996 ms |
| 冷进入后首次操作 | 195 ms | 212 ms |
| 热进入 | 642 ms | 697 ms |
| 热进入后首次操作 | 123 ms | 112 ms |

这组小样本没有证明整体进入更快，冷进入和热进入中位数反而上升。收益是已测得的请求体积下降与按需加载边界，不将其表述为首屏耗时改善；新增异步展示层的调度开销仍值得后续持续观察。
