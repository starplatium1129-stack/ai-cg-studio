# 桌面 UX 审计与优化 · 2026-09-07

> 历史审计快照（2026-09-12 整理）：正文保留当时证据，旧结论和下一步不代表当前状态或授权。当前事实见 [办公机独立审计](office-independent-audit-2026-09-12.md)，尚未完成及暂停事项见 [未来规划](../../roadmap.md)。归档不表示其中问题全部解决。

> 历史记录：归档不表示全部问题已解决；测试结果只代表原记录时点。未闭环事项统一由 [未来规划](../../roadmap.md) 跟踪，实施前重新复现。


本轮以桌面端的连续操作为重点，覆盖首页封面、画册浏览与回到工作台、角色查找、绘图素材切换、全局搜索和历史记录恢复。移动端不作为本轮扩展重点。

## 已完成

| 问题 | 优化结果 |
| --- | --- |
| 接入主机拷贝的样张后，旧 home-hero.json 覆盖了正确封面 | 首页固定采用项目内原有宁宁、夏目 WebP 封面；其他 CG 仍由本机样张目录提供 |
| 全局搜索将作品 ID 当作场景 ID，作品打开路径错误 | 作品明确进入历史恢复入口，场景继续进入场景入口；每次打开搜索更新最近 300 条作品，按时间排序 |
| 同一个工作台里切换历史链接时只改地址，没有恢复内容 | 补齐历史链接变化检测；记录缺失时重新读取历史，同一链接不反复覆盖编辑，页面离开后取消迟到的恢复请求 |
| 热门角色 CG 的创作按钮丢失角色与场景 | 通过当前目录精确匹配角色及所属蓝图，再走已有工作台深链；旧蓝图不存在时明确只载入角色，不猜配方 |
| 点击画布中的“挑选场景”会跳走 | 原地打开场景素材页签并转移焦点；从已有场景或蓝图进入工作台时默认显示场景页签 |
| 离开画册后重新筛选，找图步骤重复 | 缓存画册筛选和已加载内容；离开时关闭大图并停用快捷键，防止隐藏查看器干扰工作台 |
| 画册缺少顺手的重新读取与清除操作 | 新增刷新、失败重试、清除筛选；搜索优先标题匹配；关闭链接打开的大图会清理 URL，刷新不再重复弹出 |
| 大量角色和作品标签需要反复横向查找 | 增加角色名/作品名搜索，完全匹配的角色优先；Enter 选择首项，并提供明确的无结果状态 |
| 每次画册搜索重复扫描角色名映射 | 缓存角色显示名及文本索引，避免逐个条目反复遍历整份清单 |

## 验证

- 191 项前端单元测试通过，包含新增的样张目标映射、同页历史恢复和离页取消测试。
- 14 项桌面浏览器回归通过，覆盖原封面、旧作品恢复、同页切换历史、角色搜索、画册返回保留筛选、热门蓝图衔接、重试和键盘操作。
- 26 项热门角色/提示词契约通过。
- 类型检查、生产构建与路由体积预算通过；对比度检查通过；改动文件 ESLint 无错误（工作台已有体量警告仍存在）。
- 浏览器核对：工作台仍在原路径内切换素材；搜索恢复后故事输入值实际变化；热门 CG 正确带入角色和蓝图；没有提交真实生图任务。

## 交付范围

改动位于当前项目源码和本机预览，未改写已经安装的桌面程序。主力机下一次打包需要包含这些修改。本机未进行真实生图、视频推理或音频模型验收，这些需在主力机的完整环境中复核。
