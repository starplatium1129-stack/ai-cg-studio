# 全站交互细节审查与优化（2026-09-12）

范围：当前 1.7.1 源码及本机桌面增量版。保留既有配色体系和滑动动效，检查状态联动、键盘/输入法、焦点、反馈、错误/空状态、照片叠字与窄屏布局；不改场景提示词、服装绑定、模型参数或真实图片。本机没有出图环境，生成链路验证使用受控模拟上游。

## 已落实的细节修复

| 操作路径 | 确认的问题与最终行为 |
| --- | --- |
| 首页角色切换 | 宁宁与夏目的选中底板/边框分别取淡紫/淡琥珀，保留文字墨色及原滑动动效；沿用上一轮已体验的改动 |
| 共享滑动底板 | 选中控件宽度变化、字体载入、选择器改变时重新对齐；支持有边框的容器，无几何变化时不重复开动画，减弱动效时取消未完成动画 |
| 主导航 | 手机菜单打开后焦点进入首项；Esc 逐层关闭“更多”与菜单并回到对应触发按钮；点击菜单外关闭；从手机导航打开搜索后关闭，焦点能返回可见入口 |
| 全局搜索与弹层 | 中文输入法确认/取消候选不再执行搜索或关闭弹层；搜索增加明确关闭按钮；既有焦点陷阱保留 |
| 通知与撤销入口 | 悬停、键盘焦点、页面隐藏的暂停原因分别管理；用户仍在操作时新通知不提前消失；删除已聚焦通知后恢复计时；上滑不误判下滑消除，减弱动效下不强制位移退场 |
| 灵感场景 | 从心情推荐进入时清除互相冲突的旧筛选，避免推荐被旧角色/收藏/隐藏条件挡住；清空搜索后焦点留在输入框 |
| 作品与参考画册 | 搜索清空回焦；作品对比/信息展开及筛选选中状态有明确语义；真正空目录与筛选无匹配分别显示，无匹配时随机查看禁用 |
| 角色参考灯箱 | 兑现界面提示的左右方向键；跳过缺失参考图，按实际可查看图片决定上一张/下一张是否可点；服装选择同步选中语义 |
| 聊天输入与菜单 | 输入法 Enter 不误发送；空白发送禁用，生成期间显示回复中；更多菜单支持方向键/Home/End/Esc，关闭或选择后回焦 |
| 按住录音 | 申请设备/正在录音时保持按钮可接收松开事件，只有识别阶段禁用；补空格/Enter 操作与失焦取消，切角色取消旧录音，避免结果进入另一角色 |
| 聊天/桌宠连接反馈 | 桌宠聊天窗纯配音时仍可停止；桥接失败有明确提示；浏览器“完整房间”进入 `/chat`；浏览器切角色同步标题与状态 |
| 衣柜与图片叠字 | 衣柜使用与原生按钮操作一致的选中语义，Esc/选中后回焦；房间说明加不透明底板，消除照片背景导致的不可读文字 |
| 绘图工作台 | 生成不可用时常驻显示具体原因；镜头、情绪、光照、构图和色调的可见选中态同步到辅助技术 |
| 视频与分镜 | 模式徽标区分可生成、离线可编辑、待装权重；删去重复探测提示；描述输入有名称、模型/画幅/服装选中态可识别 |
| 分镜反馈与操作 | 接回原先未传给模板的错误/草稿恢复提示，重试有忙态；禁用原因按输入/Seed/准备中/提交/取消/拼接分类，不再误报“0 个镜头描述不完整”；提交及运行阶段冻结编辑控件 |
| 分镜参考与脚本弹层 | 参考图改为可用键盘删除的按钮，删除后回到下一参考或上传入口；脚本弹层支持焦点限制、Esc、关闭回焦和窄屏内部滚动；取消加载文字透明度脉冲 |

- 核心修复后进行 18 个入口 × 深浅主题 × 1440/390 两种宽度的页面遍历，共 72 个页面状态；36 组测试通过，未发现横向溢出或脚本异常。已查看四张全站联系表，并放大检查聊天、工作台、作品、控制面板等页面。
- 图片叠字、视频文案及参考删除焦点是看图后补充修复，另行定向构建/浏览器复验；早先的截图不冒充这些后续修改的最终截图。
- 最终前端 89 个测试文件、622 项通过；新增覆盖通知焦点计时、输入法 Esc、参考图方向键和视频状态提示。全局对比度门禁不能替代照片叠字的实际合成色检查，后者在浏览器单独验证。
- 浏览器全套结果及最终定向结果以 [本轮机器证据](../../evidence/interaction-detail-polish-2026-09-12.json) 为准。原失败日志保留，不把修复前后分轮测试描述成同一轮全套通过。

本轮全套浏览器首轮 **479 过 / 2 失败（481 项，含 40 项仅截图采集）**，两项失败均为新增导航测试点击被菜单覆盖的标题而超时。纠正点击位置并完成照片叠字/视频补改后，最终定向复验 **54/54 通过**，包含新增的两主题叠字与分镜弹层验证。最终源码另重跑 22 步检查、622 项前端测试与生产构建，均通过；不机械重复未改动的后台模型/契约测试。

最终生产包体仍在硬预算内：工作台路由 JS 120.4 / 140 KiB，最大路由闭包 CompanionView 509.8 / 580 KiB；Live2D 浏览器懒块保持原有 923.4 / 1000 KiB 提示。本次不把包体变化推断为加载速度或功耗提升。

初始门禁遇到两类维护问题：部分新增行被 Windows 写成 CRLF，已归一为仓库要求的 LF；旧 ArchiveStatePanel 测试要求画册空结果一律为 filtered，已调整为区分空目录与筛选，并补真实浏览器行为测试。新增导航测试最初点击了菜单覆盖下的标题而超时，后改为点击真实菜单外空白区，仍保留关闭与焦点断言。
