# 网站体验审计与优化 · 2026-09-09

## 范围与结论

本轮按九个维度审计，重点落实「首页理解 → 选择场景 → 进入绘制 → 回看作品」的入口体验。直接检查首页、场景库、绘制台、参考画册、作品页与上手指南；不把界面通畅等同于真实出图成功，也不把启发式审计等同于用户调研或转化率实验。

核心问题是品牌情绪强于功能解释、首访主按钮通往画册、首次创作路线位于长页面下方。保留现有角色视觉与绘遇品牌，增加明确的创作定位、主次入口、三步指引与生成/保存说明。

## 九维审计

| 维度 | 本次发现 | 已实施优化与边界 |
| --- | --- | --- |
| 价值主张 | 「影像手帖」「收藏日常」未明确这是 AI CG 创作工具 | 首屏明确 AI 角色创作、选角色与场景、生成二次元 CG；同步页面描述 |
| 信息架构 | 首页灵感入口暗含当前装饰角色过滤；新手需在大段画册后寻找工具 | 灵感入口直达全场景库；创作三步提前到画册前；保留进阶工具与资料分组 |
| 用户旅程 | 首访、已有想法、已有草稿的需求不同 | 首访先选场景；已有想法直达绘制；有草稿或最近作品仍保留续作优先；回看作品可从三步导航到达 |
| 交互设计 | 首次操作缺少预期说明；说明入口距按钮较远 | 明示确认参数后才生成；使用原生 details 提供按需说明，支持键盘开合；入口均为真实链接 |
| 视觉层级 | 手机先呈现角色大图，动作入口靠后 | 手机先展示定位、主次按钮，再展示角色图；桌面保持品牌角色双栏；使用既有主题令牌与线条图标 |
| 转化路径 | 首访主 CTA 是参考画册，容易形成连续浏览 | 主 CTA 改为「选场景，开始创作」，画册降为次按钮；没有添加自动生成或不可验证的成功承诺 |
| 品牌识别 | 上手指南残留旧品牌；文档导航深色字标在浅色背景消失 | 指南统一绘遇 HUIYU；文档导航切换现有深浅字标，读屏品牌同步；常用导航名称与主应用一致 |
| 内容策略 | 指南只讲 SD，包含旧界面方位、按钮名称与固定耗时描述 | 重写上手路径，说明 SD / Anima / Krea 2 服务条件、任务反馈、样张差异与备份；删除固定出图时长承诺 |
| 性能与信任 | 场景加载串行阻塞历史读取；开发首页 JSON 导入 404；指南浅色样式缺失且被网关拒绝 | 场景与本地历史独立加载，最近作品图懒加载；区分 Vite 模块导入和网关数据；精确开放共享浅色 CSS，其他源码 CSS 仍拒绝；补充存储与生成边界 |

## 本轮证据

- 工作区开工时无未提交改动；没有修改提示词、场景蓝图、服装、定稿数据或分级策略。
- 首页、新手路径：深浅主题 × 1440 / 768 / 390 宽度，共 6 组浏览器检查；无横向溢出、无页面脚本异常，CTA 点击进入场景库、键盘展开生成说明均通过。草稿续作链接单独验证通过。
- 手机 390 宽度的主 CTA 底边位于页面 y=400；768 宽度为 y=467；桌面为 y=529。属于本地布局测量，不是转化率数据。
- 现有布局回归：上述五个核心页面 × 两主题 × 三种宽度，30 项通过。
- 现有首页回归：角色图/文字/强调色联动、减少动态效果、性能预算，3 项通过。
- 新增步骤卡实测对比度：深色编号 8.21:1、标题 14.75:1、正文 9.26:1；浅色编号 7.20:1、标题 16.49:1、正文 8.72:1。其余全局及角色令牌由全量门禁覆盖；已查看双主题首页、移动端与指南截图。
- 生产首页本机样本：资源有效负载 3,655,720 bytes、非字体请求 50 个、DOM 471–472 个；首页预算测试通过。未开展公网弱网、真实用户 LCP/INP/CLS 或转化率统计。
- 构建预算通过，但绘制台 JS 140.0 KiB / 140.0 KiB、CSS 111.5 KiB / 115.0 KiB，仍接近上限，不应据此宣称性能已无优化空间。
- 浅色指南修复后重新验证：共享浅色 CSS 返回成功，其他源码 CSS 返回 404；相应网关契约测试通过。

原始截图与执行日志位于本机被忽略的 `scripts/archive/experience-audit/`；可随本轮任务查看，不作为跨设备可用的仓库资产。

## 验收与待解决项

首次正常模式 `gate:full` 因参考库未配置而失败：2,534 个已登记参考 URL 对应文件不可用，另有 1,974 个 pending。未修改索引或使用占位掩盖缺图。后续按工作流允许的 `AICS_REFERENCE_AUDIT_MODE=structure` 完成代码门禁，结构模式不证明参考资产存在。

结构模式全量检查包含类型、静态质量、前端、434 项 unit、25 项契约及构建。

- 最终全量结果：结构模式 `gate:full` PASS，耗时 1 分 53 秒；文档链接检查 134 个文件、668 个本地链接、60 条重定向，0 个坏链接。
- 未执行：真实图像生成、完整场景内容审核、公网远程实测、桌面安装同步。
- 待解决：参考库同步；绘制台接近打包预算；其余静态文档仍需逐页清理历史内容与图标。本轮没有把所有静态文档重新验收。
- 后续效果评估建议：以首访进入场景、进入绘制、首次生成成功、保存/下载、回访续作为漏斗阶段，分别统计放弃率与耗时；当前没有用户行为基线，不声称转化率提升了某个比例。
