# 任务中心、候选对比与角色素材体验

> 历史记录：本文保留原始结论与验证边界，归档不表示遗留事项已经完成。当前优先级见 [未来规划](../../roadmap.md)。

日期：2026-09-08。本轮对应全局任务中心、候选挑图流程、常用角色素材三项。

## 使用入口

- 主导航与控制面板新增“任务”入口，显示当前处理数量。可筛选进行中、待处理和已完成任务，停止可取消的任务、重试失败批次或返回对应工作台。
- 作品册进入“选择”，勾选 2–4 张后点击“对比挑选”。完整显示图片与种子、尺寸、模型记录，可设为本组首选、暂不采用、恢复候选并继续微调。
- 批量出图完成后可直接对比候选；超过四张时明确标为“对比前 4 张”，其余可以在作品册重新选择。
- 角色档案新增素材状态，核对默认服装参考图实际能否读取，并支持重新检查。角色目录与绘图选择卡统一头像框、裁切和失败占位。

## 任务生命周期

绘图、批量、反推、视频和分镜批次接入统一进度摘要。绘图/视频工作台采用缓存，正常切换到作品册、控制面板等页面时继续执行；回来后保持现场，视频的新跨页输入仍会被消费。

浏览器中，在任务运行时通过导航打开需要独立安全策略的房间页面，会在新窗口打开，原窗口任务继续。直接整页重载仍有提示；关闭或刷新执行窗口不等于后台常驻。任务摘要保存在 IndexedDB，重开时旧的运行记录显示“待检查”，不假装仍在运行，不自动重复提交生成。视频沿用已有的任务编号重连能力。

“停止”和“重试”使用各功能已有控制接口。无取消能力的阶段不显示停止按钮；失败视频可返回工作台处理。任务摘要本身不保存原图，未入册的单张结果继续由现有临时成片机制管理。

## 挑图与存储

对比最多同时读取四张原图；关闭或离开后释放本组件创建的 object URL。窄屏可横向滑动，图片按完整构图显示。

首选自动收藏，暂不采用只改变候选标记，不删除图片。整组首选修改一次写入，失败保留旧标记；后台新图入册与作品标记使用同一串行存储通道，避免新图覆盖刚保存的首选，也避免并发入册漏图。

## 素材核验

当前 158 位热门角色的 WebP 缩略图均已存在，逐文件解码验证通过。宁宁、夏目、雷电将军、芙宁娜的默认参考图共 28 张均可通过实际图片请求读取。本轮没有重复生成、覆盖其他会话刚补好的角色素材。

头像使用既有轻量缩略图，统一比例与取景；缺图时显示角色首字，不把占位算作完成。素材检查区分 pending 与可读取图片，并兼容常规服装目录及旧版共享设计图路径。“可读取”不代表本轮完成了全库视觉审核。
