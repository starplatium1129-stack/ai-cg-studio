# 聊天与桌宠功能闭环修复

日期：2026-09-09。本轮从当前工作流、功能状态、历史体验审计和实际代码定位问题，优先处理聊天与桌宠工具链路；不代表全项目所有功能已完成真机验收。

## 本轮修复

- 工具执行期间停止回复：网关请求携带取消信号；桌面桥等待可中断；每个工具与下一轮聊天开始前检查取消状态，停止后不继续排队中的操作。
- 看屏工具回传：capture_screen 成功后的图片与 read_image 一样送入下一轮视觉请求，避免模型只收到“截图完成”的文字。
- 断线与超时：保留已收到的回复并标记中断，仍显示错误；空占位才移除。刷新后片段仍可读取，并可继续聊天。
- 草稿恢复：正常发送时取消尚未触发的草稿保存计时，避免旧文字在发送后重新写回。
- 工具失败：无效 JSON 或非对象参数不再以空参数执行；HTTP 失败和缺失输出有明确文字反馈；达到工具轮次上限提示停止，避免显示省略号冒充完成；未启用工具时不执行异常返回的调用。
- 流连接清理：收到 done 立即结束消费，错误退出也取消 reader 并释放锁，避免回复完成后仍等待服务端关闭连接。

## 本次验证

- 新增前端回归 9/9：原生工具取消、网关工具取消、图片回传、断线保留、草稿防回写、错误参数、工具轮次上限、完成事件与异常流释放。
- 浏览器聊天回归 8/8：包含新增深浅主题断线、刷新持久化和再次发送；既有流式聊天、用户记忆、翻译配音、主动停止及情绪协议用例通过。网关连接模拟上游，新增断流用例在浏览器注入故障。
- 前端类型检查与本轮文件 ESLint 通过。
- 默认 gate:full 未通过：本机没有配置参考素材根目录，2,534 个参考 URL 对应文件无法核验。
- 按工作流允许的 AICS_REFERENCE_AUDIT_MODE=structure 执行 gate:full 通过：21 步 check、前端单测、434 个 unit 用例、25 个接口契约文件、生产构建及打包预算；随后新增的两项取消/上限单测另行执行通过，最终代码重新通过类型检查与 ESLint。

## 验收边界

没有执行真实模型看屏、真实语音设备、Live2D 原生设备或桌面安装。图片回传验证只确认请求包含图像，不能替代真实视觉模型质量验收。参考图仍需主力机默认模式核验，没有改索引掩盖缺图。

取消会解除前端等待并阻止后续操作，但现有桌面桥不提供终止已启动原生命令的接口；网关请求中止同样不保证服务端已启动的操作回滚。真实设备取消与后台资源回收继续保留在规划中。
