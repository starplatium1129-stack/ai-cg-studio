# UI 布局、遮挡与可读性审计

日期：2026-09-08。本轮在独立工作区审查，保护主工作区正在进行的角色/蓝图数据编辑。只调整布局、主题表现、通知与界面入口，不改提示词内容和生成参数。

## 覆盖范围

- 17 个实际页面：首页、灵感场景、角色场景库、绘图、视频、聊天、画册、作品册、角色档案、画风、模型、场景管理、色彩情绪、剧本、桌宠、独立聊天窗、控制面板。
- 深色与浅色；1440、768、390px 的页面巡检，共 102 组首屏截图。
- 1280、1024、390px × 640px 矮窗口，检查导航、搜索、聊天设置、桌宠设置、换装弹窗、专家参数区及页面底部，共 48 组展开/滚动截图。
- 浏览器实测横向溢出、运行时错误、目标点击是否被遮挡，以及关键文字与实色背景的 WCAG AA 对比度。
- 图片叠字结合截图核对：不能用图片后方的 CSS 背景色计算“伪对比度”；模态窗口阻挡背景、导航覆盖已滚走的旧内容也不直接算作缺陷，需验证控件能否实际到达和点击。

## 已修复问题

| Before | After | Why |
| --- | --- | --- |
| 绘图页约 1024px 宽时，参数区横跨整个网格，与左侧角色/素材重叠 | 901–1099px 显式分配 story / stage / decisions 区域；窄屏参数区有独立网格位置 | 修复真实覆盖，角色特征按钮与参数页签均可点击 |
| 提示条在画布中下方堆叠，自动选引擎也弹提示 | 通知停靠右下角，限定宽度和最大高度；自动路线选择保持安静，显式操作仍有反馈 | 减少反复遮挡主要创作区，长提示可滚动 |
| 点提示条叉号后仍不关闭 | 拖拽处理跳过内部交互控件；关闭按钮有独立点击与焦点区域 | 父容器 pointer capture 原先抢走了按钮 click |
| R15 徽标深色约 4.19:1、浅色约 2.62:1 | R15/R18 使用不透明主题底色、语义文字色和描边，实际计算通过 4.5:1 | 不再继承不适合半透明色块的反色文字 |
| Anima 已连接徽标整体 opacity=.72，浅色文字约 3.83:1 | 保留完整文字透明度，用原有语义色区分状态 | 状态不抢眼不应以降低文字可读性实现 |
| 桌宠设置菜单被“加载立绘”等按钮覆盖 | 立绘舞台建立独立层叠边界；菜单使用清晰主题底色 | 限制组件内部层级外溢，而不是不断提高全局 z-index |
| 桌宠浅色输入区透出背景，白字/占位字模糊；姓名和选中设置文字偏淡 | 输入区用主题实色表面、输入文字与占位令牌；发送、姓名和设置状态使用对应主题色 | 背后的插画与光晕不再决定文字对比度 |
| 浏览器桌宠菜单出现两个相同“完整房间”入口，其中一个无操作；“打开完整工作台”也无操作 | 按浏览器/桌面分别渲染有效入口；浏览器工作台按钮执行真实导航 | 消除重复、无效操作造成的困惑 |
| 换装弹窗浅色灰底灰字，模式/服装选中项使用白字 | 上传区、输入、选择器和选中项改用主题令牌 | 关键提示与选中状态通过实际对比度检查 |
| 矮窗口中换装预览固定 440px，标题和关闭操作易离开视野 | 预览高度按视口收敛；标题区可换行并保持可见，弹窗高度按 dvh 限制 | 640px 高度下仍能读说明、切换模式和关闭 |
| 换装组件携带大段样式，修改布局使单体预算回涨 | 样式移到独立 scoped 样式文件，组件有效行数降到约 399 | 不放宽单体门禁，布局规则可单独维护 |
| 独立聊天窗只有普通文本标题 | 保持视觉尺寸的同时使用 h1 | 页面结构和辅助技术导航完整 |

## 验证

新增 `tests/e2e/ui-layout.spec.ts`：102 个页面矩阵用例 + 12 个专项用例，共 114 项，并登记到关键浏览器回归入口。单独复验可运行 `npx playwright test tests/e2e/ui-layout.spec.ts --project=desktop`。

## 使用与交付

关键浏览器入口已经包含本轮检查：`npm run test:e2e:critical:run`。独立预览服务可通过 `AICS_UI_AUDIT_URL` 指定地址，默认使用本机 3000。

源码与报告提交范围不包含并行会话的角色/蓝图修改。审计截图保存在本轮 runtime 证据目录，结果记录分别为 ui-regression-final.log、ui-gate-final.log、ui-survey-final.log 与 ui-states-final.log。

本轮是界面验收，不宣称所有生成模型、所有角色图片或所有桌面原生窗口都已重新测试。
