## 已修复

- **单人引擎切换被误禁用**：工作室模式原先无条件套用双人能力限制。现在仅 `triad` 受限制，宁宁/夏目可切换 Anima 与 Krea 2。
- **深链色调被覆盖**：场景默认推断曾覆盖 `?mood=`。显式色调现在在场景加载后应用；历史及草稿恢复继续保留自己的参数。
- **备份确认框被遮挡**：确认框与恢复面板同层，造成按钮点击被拦截。增加确认层级，确认期间暂停底层焦点拦截，避免 Tab/Esc 争抢。
- **备份重复确认**：界面完成确认后，不再额外弹系统确认；直接调用恢复函数仍默认要求确认。
- **参考图缺失仍可点击**：图片加载失败后显示“本机暂无参考图”，禁用卡片及放大入口，翻页跳过已知不可用项。不修改主力机素材目录和参考图元数据。
- **搜索高亮损坏特殊字符**：先在原文匹配，再分别转义命中与未命中片段；覆盖 `&`、`<`、正则字符与 HTML 输入。
- **静态数据版本未同步**：使用现有 `syncDataVersion` 同步版本，避免旧缓存。
- **生成按钮含歧义且角色写死**：恢复明确的“生成图片 / 正在绘制…”反馈。
- **依赖安全修复**：nanoid 3.3.16 → 3.3.18，qs 6.15.3 → 6.16.0；兼容范围内升级，依赖审计为零漏洞。锁文件项目版本同步到 package.json 的 1.5.5。
- **维护性**：拆出控制页响应式样式及场景高亮工具，未上调体量预算；加载首帧使用主题变量；更新重构后已过时的界面测试定位和架构检查。
