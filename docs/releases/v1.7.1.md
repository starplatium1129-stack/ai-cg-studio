# 绘遇 HUIYU 1.7.1

修复 2026-09-12 办公机独立审计确认的聊天记录丢失、流式回复截断和远程聊天目标越界问题，并纠正桌宠绘画工具的完成状态。

## 修复

- A01：正确处理角色修订号 0，清除一个角色不会覆盖另一窗口新增的其他角色消息。
- A02：分离聊天记录解析与写回失败；存储配额异常保留原始记录和已加载会话，不再用空历史覆盖。
- A03：远程自配兼容 API 仅允许公网 HTTPS；校验全部 DNS 结果并固定实际连接地址，拒绝私有、loopback 和转换地址，不跟随重定向。本机自配和站主授权托管继续可用。远程自配使用公网直连，服务器环境代理仍供本机及托管配置使用。
- A04：跨窗口合并保留消息对象与历史数组，流式期间保存、合并其他窗口新增消息后，后续正文仍可完整保存和重载。
- A05：角色绘画工具明确返回 `draft` 和真实 JSON 草稿路径；未接入生成任务时不返回虚构图片、不增加生成奖励，草稿写入失败明确报错。工具尚不能直接出图。
- 角色资料页为页头、状态栏和标签预留首屏空间；浏览器回归按当前目录、导航、懒加载面板和主题契约更新，样张交接/重试使用受控 fixture。
- 补修复验发现的角色入口转场异常：移除全局浏览器跨文档自动转场，保留 Vue 页内过渡，不屏蔽运行时错误。
