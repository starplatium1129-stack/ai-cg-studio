# 绘遇 HUIYU 1.6.0

本次整合 v1.5.10 之后的创作体验、桌宠交互和数据可靠性改进。项目统一使用“绘遇 · HUIYU”品牌，GitHub 仓库更名为 `starplatium1129-stack/huiyu`。

## 创作与界面

- 重整首页与创作入口，补充上手指引、最近创作续接和统一导航。
- 改善控制面板布局、角色粒子肖像、深浅主题及窄屏可读性。
- 桌宠小窗的角色切换与设置按钮不再挤成竖排；优化设置弹层、输入区和艺术浮层的文字对比度。

## 聊天、记忆与桌宠

- 断线或超时保留已经收到的回复，停止后不继续执行排队中的工具。
- 修复看屏图片未进入后续视觉请求、草稿回写、中文输入法回车误发和跨窗状态刷新吞草稿。
- 角色知识加载可重试，长背景和旧格式身份描述可召回；长期记忆保存失败不再误报成功。
- 统一勿扰、安静时段与提醒队列，切换角色清除旧台词；改善好感度同步、异常值和失败处理。
- 修复 Live2D 过期加载、动作状态和交互锁问题。

## 视频、参考卡与作品

- 修复新预览仍提交旧首帧、重复生成引用已清理文件，以及首尾帧草稿恢复后无法继续的问题。
- 分镜 AI 建议写入正确字段，撤销文本整理保留首帧；迟到结果不覆盖用户的新编辑。
- 改善参考卡切换、并发上传、角色编号同步、批量重试和取消；一键首帧支持从任务中心停止。
- 原图导出保留实际格式，不再把 JPEG/WebP 命名成 PNG，也不以缩略图冒充原图。
- 合并场景、样张和内容修正，保留定稿与本机/远程访问边界。

## 数据与工程可靠性

- 备份恢复先暂存图片，再统一提交作品和项目；失败保留原库，避免同 ID 图片覆盖和不完整恢复。
- 图片清理保护项目、回收站与当前草稿引用；保存期间的新修改继续标记为未保存。
- 统一蓝图、归档、维护快照和诊断包下载，改善任务重连、资源释放与错误恢复。
- 补齐本机桌面工具链检查和可重复打包入口，增加单元、接口、浏览器与原生渲染回归。

## 升级说明

- 原应用标识、安装兼容信息和本地数据格式继续沿用；仓库改名不会要求重新建立作品库。
- 旧仓库地址会跳转到新仓库，后续克隆及拉取建议使用新地址。
- 具体安装与自动更新方式请以本 Release 顶部说明为准。升级前可在应用内导出重要作品备份。
- 测试覆盖不等于所有模型和素材均已完成真实画面验收：参考库待补素材、真实视频一致性和部分设备联动仍按项目规划继续验证。
