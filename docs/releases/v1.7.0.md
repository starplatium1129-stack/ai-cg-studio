# 绘遇 HUIYU 1.7.0

本次发布整合 v1.6.1 之后的一系列深度稳定性与架构演进，重点涵盖 Live2D 原生性能节拍、工作台面板懒加载、跨标签页并发存储事务、画师转译保护与海量场景蓝图规范化对齐。

## Live2D 与桌宠引擎

- **原生帧率节拍控制（Frame Pacing）**：在 Rust 桌面原生层引入渲染节拍控制，大幅降低桌宠挂机与后台运行时的 CPU/GPU 占用。
- **意图时序队列（Latest Intent）**：重构动作、表情与语音切换时序，彻底解决高频点击与快速切换角色时的异步竞态。
- **生命周期与视线交互**：优化窗口最小化/恢复时的状态冻结（Visibility）与视线追踪（Pointer Gaze），平滑视线跟随与情绪时钟。
- **画质控制面板**：新增桌面端 Live2D 渲染画质等级调节面板，配置自动记忆。

## 绘图工作台与包体性能

- **次级面板按需懒加载**：绘图工作台的素材抽屉（Material Drawer）、决策轨（Decisions Rail）等复杂组件改为首次使用时按需挂载，同时保留操作状态，显著降低主工作台首次渲染开销。
- **样式与包体精简**：清理冗余分类衍生逻辑，全站 18 个主路由闭包均严格通过包体预算限制。
- **字体与产物预压**：自动清理冗余 `.woff` 产物，全面推行高效 `.woff2` 搭配 Brotli 预压缩。

## 数据事务与存储安全

- **跨标签页并发保存保护**：加固作品库（Gallery Storage）事务锁，消除多页面或异步任务并发保存时的丢记录和临时缓冲误删隐患。
- **出图结果代际与旧缓存清理**：`useTempResult` 支持代际比对，慢网络响应不再覆盖新出图结果；手动刷新后强制废弃旧缓存。
- **定稿场景字节级保护**：严格锁定 100 条手工定稿场景基线，修复批量任务造成的定稿字段漂移；重构定稿捕获工具支持无历史环境安全降级。

## 提示词系统与场景蓝图

- **画师括号转义保护**：修复 Anima / ComfyUI 下带括号消歧义画师名（如 `ASK`、`Hiten`、`LAM`、`SOLar`）在提示词编译时被误切或权重破坏的问题。
- **场景蓝图全库对齐**：完成数十个批次的场景与角色蓝图审核，修复明日方舟、蔚蓝档案、进击的巨人、月姬、辉夜大小姐、86、紫罗兰等作品的服装绑定脱钩、动作与道具提示词漂移。

## 桌面安全与工具链

- **网关沙箱与路径防护**：加强本地网关对符号链接越界与路径穿透的边界校验；旧 SD 代理原生接口增加严格访问限制。
- **语音输入鲁棒性**：修复取消旧录音会话时污染新识别任务的问题，加固 Permissions-Policy 策略。
- **桌面快速部署**：优化 `deploy-desktop.bat` 增量热部署体验，支持自动清理失效历史 Hash 文件与 WebView2 缓存隔离。

## 升级与兼容说明

- **完全向后兼容**：数据格式与用户已有作品、自定义模型及配置完全兼容，无需重建作品库。
- **样张目录保护**：样张与用户文件依旧独立保存在 `AI/` 目录或用户自定义工作区，升级不会改动您的已有创作资产。
