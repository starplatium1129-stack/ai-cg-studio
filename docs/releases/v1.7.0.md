# 绘遇 HUIYU 1.7.0

> 2026-09-12 校订：本页说明代码变化，验收以 [本次办公机独立审计](../archive/audits/office-independent-audit-2026-09-12.md) 为准。已撤下没有本轮证据支持的性能提升、全库完成和完全兼容承诺。

## Live2D 与桌宠

- 原生渲染循环加入帧预算与隐藏窗口等待；默认目标帧率保持 165，可按配置调整。纯 Rust 节拍测试不代表真实 CPU/GPU 或闲置功耗已测。
- 动作/表情使用意图序号处理过期异步结果，并调整窗口可见性、模型时钟和视线跟随。
- Live2D 画质设置提供纹理档位。真实 overlay、两角色动作/换装、DPI/多屏和休眠恢复仍须在目标程序验收。

## 绘图工作台

- 素材抽屉、专家控件等次级组件按需加载，并保留相应操作状态。
- 本次构建的工作台路由 JS 为 120.3 / 140 KiB；最大路由静态闭包为 CompanionView 508.5 / 580 KiB。Live2D 浏览器懒块仍有 923.4 / 1000 KiB 的预警。
- 包体收敛不能直接推断首次进入更快；速度改善需同机、同条件的前后测量。

## 数据与提示词

- 作品库使用跨标签页锁管理读改写；聊天历史是另一套存储路径，本次仍复现数据丢失和流式合并问题。
- 临时生成结果使用代际校验；定稿工具支持基线/历史来源选择，100 条定稿保护在本次门禁通过。
- 提示词编译包含画师转义保护与服装覆盖等变更。原场景语义审计仍暂停，候选人工审核和部分场景真实出图未完成，不宣称全库画面已对齐。

## 网关与升级边界

- 文件工具检查工作区路径及链接目标；通用命令默认关闭，显式 trusted 模式以当前系统账户权限运行，不是操作系统沙箱。
- SD 代理来源限制、语音会话取消和页面安全策略有工程回归；远程聊天自定义目标与桌宠生图工具仍有本次审计列明的缺陷。
- 当前依赖树审计未报告已知漏洞；安装、迁移、真实推理和旧窗口刷新仍须目标环境验收。作品库并发操作依赖 Web Locks，不能对未测试的旧 WebView2 或浏览器作完全兼容保证。
- 桌面同步使用 `deploy-desktop.bat`；素材与用户作品沿用独立工作区，本轮文档整理不迁移或删除这些资产。
