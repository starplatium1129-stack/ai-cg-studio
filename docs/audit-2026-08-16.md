## 一、安全面（最高优先级）

1. ✅ **desktop-tools `run_command` 任意命令执行（曾 Major，现修复）**
   - 现象：run_command 无命令白名单，模型工具调用可在本机执行任意系统可执行文件；
     remote 隧道访客也可置 `companionTools:true` 让共享 LLM 挂出工具 schema。
   - 修复：`routes/desktop-tools.js` 增加 `ALLOWED_COMMANDS` 白名单（python/python3/
     pythonw/pwsh/powershell/node/npm/npx/git/conda）或工作区内相对脚本（绝对路径/
     `..` 拒绝）；`routes/chat.js` 的 `companionTools` 仅 `isDirectLocalRequest` 放行。
   - 残留取舍：白名单解释器内的参数（如 `node -e`）仍由模型驱动，个人本地工具可接受；
     执行端本身仍 `localOnly`。

2. ⏳ **chat.js 请求体 14MB 与 AGENTS.md「256kb」契约漂移**：14MB 是给多模态 base64 图留的
   传输上限（单图 ≤12MB），多模态不参与裁剪、无总图数/总字节上限。建议 normalizeMultimodalContent
   加「最多 8 图 / 总 base64 ≤ 18MB」显式上限，并把 AGENTS.md 契约措辞更新为「文本 24 条/12000 字
   裁剪 + 多模态图数/体积显式上限」。
