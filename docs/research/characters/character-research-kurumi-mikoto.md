# 动漫角色原作设定调研：时崎狂三 & 御坂美琴

> 用途：供「角色→场景+词条」配置使用（AI 绘画 / 场景 + 词条）。
> 方法：每条关键特征要求 ≥2 个独立权威来源一致才采信；不足 2 源标注「未确认/not confirmed」。所有外貌/服装/能力/性格均来自实体来源核验，未编造。
> 视野约定：左右眼方向以**角色自身视角**为准（角色左侧 = 图观者右侧）。

## 一、时崎狂三（Tokisaki Kurumi / 時崎 狂三）

### 原作与世界观
- 作品：《约会大作战》DATE A LIVE（作者：橘公司）
- 世界观：近未来现代都市，幼年遭「空间震」、存在由异界降临的「精灵（Spirit）」。狂三是**第 3 精灵**（Spirit number: 3），代号「梦魇 Nightmare」，被称作「最凶/最危险的精灵（most dangerous and lethal spirit）」。
- 世界观依赖：**灵力魔法 × 精灵天使 × 近现代科技城镇**；登场多在现代高中（来禅高中）+ 城镇废墟，与 DEM/AST 等灵力武装对抗。
- 来源（≥7 源一致）：萌娘百科 S1、快懂百科 S2、百度百科 S3、Multiversal Omnipedia S4、MyWaifuList S5、MyAnimeList S6、animemanga S7、booru wiki S8。

### 外貌特征（精确到提示词）
- **发色**：**黑色长直发**（正规设定=黑发；「酒红/深红头发」不被任何正规来源支持，属读解红色视觉元素的误判）。
- **发型**：**双马尾（twin tails）**，系成两束。日常/人类态=齐腰**等长**双马尾（low twintails）；**精灵/战斗态=两束一长一短（uneven twintails），左长右短，模仿时钟的时针/分针**。
- **瞳色**：**异色瞳（heterochromia）**——
  - **左眼（角色左侧）＝金色时钟/表盘眼（clock eye / golden eye）**，瞳孔内含带**指针**的表盘（指针**逆时针**转动代表其剩余寿命；转动即能力发动）。
  - **右眼＝红色（绯红/酒红）**。
- **标志物**：前额**齐/斜偏分刘海**（blunt/parted）在日常态**遮住左眼**露出红色右眼；**精灵态刘海拨开露出金色时钟左眼**。「时钟之眼」的刻度圈/数字随能力发动转动。
- **身高**：157cm（S5、S6 一致）。
- **未确认项（≥3 源核验）**：「沙漏/hourglass 瞳孔」无任何正规来源（规范=带指针时钟表盘）；「锯齿/zigzag 刘海」未确认（规范=齐刘海偏分）；「左时钟眼精确刻度 3:05」仅 1 源。

### 服装（标志性）
**Astral Dress 灵装 = 神威灵装·三番「Elohim」**（红×黑哥特洛丽塔）：
- **「Elohim」是灵装/Astral Dress 名，不是天使名**（天使是「刻刻帝 Zafkiel」）。
- 黑色连衣裙主体 × 血红蕾丝装饰/褶边、马甲式长裙、胸前蕾丝蝴蝶结；**双腿黑色连裤袜/长袜（变不变身都穿）** + 黑色厚底/高跟靴。
- 头顶**大红网纱发箍（lolita hairband）**、红黑**领圈/choker**。
- 日常休闲态为「黑白萝莉裙」（S2 口径）。
- **未确认/纠错**：prompt 常见「Phantom / Umbriel」**不是她的灵装/天使名**（Phantom 是另一角色凛绪的化名）；「仅单侧长筒袜」「鱼网袜」「明示束腰」「黑厚底鞋（单源）」未确认；正统画=**双腿黑连裤袜**。
- Danbooru 可识别服装标签见下节词条。

### 武器 / 道具
- **天使「刻刻帝 Zafkiel」= 巨大时钟，出现在她背后**（超过身高两倍）。
- **一对燧发枪：短枪（pistol）+ 长枪（musket），即时钟的时针/分针**；以数字作子弹，压 12 点对靶再开枪。⚠️「两把完全相同的成对手枪」未确认（实为手枪+步枪各一）。
- 经典设定：对自己用时间系能力时**朝自己头部开枪**（机制已确认）。
- ⚠️ **Kurumi 本人不使用剑**（剑仅出现在平行世界精灵`<Beast>`的"第三剑"）——「狂三持剑」未确认。

### 性格气质
- **表面**：温柔、优雅、礼貌的大小姐 / 温和神秘的转校生（elegant, well-mannered）。
- **内里**：冷血疯狂、亦正亦邪、危险的杀手/愉悦犯人格；执念主线=回过去杀死"最初的精灵"以抹消精灵存在。
- 别号「梦魇 Nightmare」，第 3 精灵、最危险/最恶精灵。
- ⚠️ 术语提醒：「病娇 yandere」为中文圈流行近似梗，**非官方正式用词**；正规用 **Yangire / Sadodere / Mayadere**（凛娇 S 系）。
- 喜好（S6）：嗜好——杀人、调戏士道；喜欢——武器、甜食、猫；讨厌——人类、AST。

### 原作典型场景（3-5 个）
1. 欧式**教堂 / 大本钟 / 钟楼**与蔷薇园（宣传美术常见背景）
2. 现代都市 + **空间震**后废墟 / 夜景
3. **时间停止/静止的时空**、布满时钟与齿轮的梦境空间
4. 夜晚月下 / 雨天深夜的天台、小巷（危险而魅惑的氛围）
5. 来禅高中**教室 / 天台**（以转校生身份登场）

### 角色专属词条建议（Danbooru 风格英文标签）
- **外貌（3-5）**：`black_hair`、`long_hair`、`twintails`、`heterochromia`、`clock_eyes`、`golden_eyes`（左）、`red_eyes`（右）、`uneven_twintails`（精灵态）、`hair_over_one_eye`（日常遮左眼）
- **服装（3-5）**：`gothic_lolita`、`frilled_dress`、`sleeveless_dress`、`red_dress`、`black_dress`、`lolita_hairband`、`choker`、`red_ribbon`、`thighhighs`、`black_boots`、`detached_sleeves`
- **道具（2-3）**：`flintlock`、`gun`（time手=手枪 / 分针=长步枪 musket）、`clock`（背后巨大时钟·天使刻刻帝 Zafkiel）
- **氛围（2-3）**：`gothic`、`moonlight`/`night`、`elegant`、`menacing_smile`

### 适合的场景类型（2-4 类）
1. **哥特暗黑 / 都市夜景**（钟楼、教堂、月下天台、夜晚灯火小巷）
2. **时间主题**（时钟表盘、漂浮齿轮、静止世界 / 泡泡梦空间）
3. **战斗动作 / 反击战**（精灵对战、双燧发枪、空间震废墟）
4. **浪漫危险邂逅**（雨夜、玫瑰、月光下的扑朔迷离）

### 明确不适合的场景类型
- 现代明亮校园日常欢乐向、治愈田园、纯轻快喜剧（与「最凶精灵」的哥特危险气质冲突）。
- 纯硬科幻硬工业（与灵力魔法精灵设定不贴合）。

## 二、御坂美琴（Misaka Mikoto / 御坂 美琴）

### 原作与世界观
- 作品：《某科学的超电磁炮》A Certain Scientific Railgun（《魔法禁书目录》Toaru Majutsu no Index 的衍生主角）。
- 世界观：**学园都市（Academy City）**——近未来高科技都市，通过**超能力开发**让青少年觉醒异能（Esper）。
- 身份：常盘台中学（精英名校）学生，**学园都市 Level 5「超能力者」中排行第三**（7 名 Level 5 之一），能力为**「超电磁炮 Railgun」/「电击使 Electromaster」**。
- 来源（≥5 源一致）：百度百科、Toaru huijiwiki、Toaru Fandom、萌娘百科、Danbooru wiki、Namu wiki（EN）。

### 外貌特征（精确到提示词）
- **发色**：**茶色/栗色（brown / chestnut / tea-brown）短发**，发长及肩、发梢略向内弯（暖棕系，三个口径一致）。
- **瞳色**：**与发同色——茶色/棕色（brown）双眼**。
- **发型**：中长发（常被称"短发"）；**发夹（hair clip / hair ornament）**——有前期单夹与后期两朵小花两种样式，是签名配饰。
- **标志物**：**签名刻点=由额前/刘海处放出蓝白色「雷枪（lightning spear/雷撃の槍）」**，约十亿伏特电流，放电闪光致盲；放电昵称「**Biri-Biri（ビリビリ）**」。
- **裙子下穿安全裤（shorts under skirt）**（长期维持）。
- ⚠️ **未确认/纠错**：「blunt bangs 钝刘海」作为 canon 发型词（Danbooru 标签存在但主 wiki 未列）；赤拇/琥珀瞳色二选一以 Danbooru `brown_eyes` 为准。
- **身高**：约 161cm（Toaru wiki / Baidu 记录）。

### 服装（标志性 · ⚠️ 纠正常识误区）
**常盘台中学制服**（近未来精英学园校服）——**不是深蓝/藏青水手服**，canon 为**浅棕/卡其混搭西装风**：
- 夏季/常服：**白衬衫 + 浅棕色背心/毛衣背心（light brown sweater-vest）+ 深卡其或灰色百褶裙**（长至大腿中部），校徽在左胸口。
- 冬季：**棕褐西装（tan blazer）+ 蓝黑棕格纹裙 + 红色蝴蝶结**。
- **白泡泡袜（white loose/slouch socks）+ 棕色乐福鞋（brown loafers）** + 安全裤。
- ⚠️ 未确认/纠错：裙色「灰 vs 深卡其」在不同 canon 页有出入（未完全 reconcile）；校徽精确颜色无文字源；「深蓝水手服」「黑丝 pantyhose」属 fan 画风，非 canon。

### 性格气质
- **热血正义、不服输（硬气）**的运动系少女；**傲娇（tsundere，3 来源确认）**——外在逞强内里温柔。
- **暴躁/急性子（brash, short-tempered）、好胜、正义感强**；带点男孩气（tomboyish）。
- **「哔哩哔哩（biri biri）」带电**招牌意象、放电炸毛、叉腰别过头的傲娇俏皮。
- ⚠️ 未确认（主要单源）：自卑(胸)、对呱太(青蛙玩偶)害羞。

### 原作典型场景（3-5 个）
1. 学园都市**街道 / 十字路口 / 天桥**（放学、巡逻日常）
2. **发射超电磁炮的电光夜空**（掏街机硬币、屈指弹出，划出蓝白光弧 + 电磁轨迹 + 音爆）
3. 便利商店 / **自动售货机**（喝果汁、Pocky，「自动贩卖机克星」梗）
4. 裙角飞扬、安全裤、蓝白电弧笼罩全身、发丝带电上扬的**战斗姿态** / 傲娇炸毛
5. **常盘台校园 / 放学 / 夜景都市**（铁砂剑·巨像战场、霓虹未来城市）

### 能力与标志道具
- **能力**：Electromaster（电击使），**Level 5 第三名**；称号「Railgun / Electric Princess 电击公主 / Tokiwadai's Ace」。
- **Railgun 超电磁炮**：两掌心并行电流+Lorentz 力加速，射速约 8发/分钟、初速约 Mach 3（~1030 m/s）、散布 18.9mm、极限射程约 50 米。
- **投射物 = 街机硬币（arcade coin）**，**不是 10 日元硬币**（粉丝误传）；有时先弹一下再发射。
- **最高电压输出 10 亿伏特**；**铁砂（Iron Sand）**可塑成剑/鞭/笼/巨像。
- **雷枪/蓝白光弧**：额前放出的蓝白色雷枪。
- ⚠️ **纠错未确认项**：**「Aero Hand」不是美琴能力**（属婚后光子/佐天泪子的风系能力）；「Arc Blades」非她命名招式；「10 日元硬币」是误传。

### 角色专属词条建议（Danbooru 风格英文标签）
- **外貌（3-5，canonical 确认）**：`misaka_mikoto`（canonical，非 `mikoto_misaka`）、`brown_hair`、`short_hair`、`brown_eyes`、`hair_ornament`
- **服装（3-5，canonical）**：`tokiwadai_school_uniform`、`sweater_vest`、`white_shirt`、`pleated_skirt`、`pantyhose`/`white_socks`
- **道具（2-3）**：`railgun_(misaka_mikoto)`、`coin`（街机硬币）、`electricity` / `electrokinesis`、`biribiri`
- **氛围（2-3）**：`city` / `urban`、`skyline`、`electric`、`energetic`、`blazer`
- ⚠️ 未确认 tag：`black_stockings`（canon 为白泡泡袜）、`electricity_arc`/`blue_lightning`、`tsundere`/`pointing`（主 wiki 未列，仅帖子级）。

### 适合的场景类型（2-4 类）
1. **现代学园都市日常**（街道、天桥、便利商店、自动售货机、放学）
2. **电磁战斗特效**（电光 / 电击 / 硬币轨道 / 电线杆下战斗）
3. **青春热血**（运动、操场、屋顶、夕阳）
4. **都市夜景城市风光**（电线、霓虹、天台望向城市）

### 明确不适合的场景类型
- 古装 / 和风时代剧、奇幻魔法宫廷、中世纪剑与魔法大世界（世界观为近未来科学都市）。
- 完全无电力 / 无现代科技元素的原始生态场景。

## 含本项目标签规范的落地提示
- 项目 `docs/tag-standard.html` 约定：角色专属服装使用**小写下划线canonical控制词**（如 `nene_witch_canonical`、`natsume_cafe_uniform`），界面显示中文，生成时用对应英文标签。
- 若为这两位角色配置 LoRA，建议按同样式绑定**角色专属服装控制词**（狂三：如 `kurumi_elohim_astral_dress`；美琴：如 `mikoto_tokiwadai_uniform`），并把上文 Danbooru 标签作为**场景补充词（姿势/镜头/环境）**追加，不得把控制词改写为自然语言近义词。
