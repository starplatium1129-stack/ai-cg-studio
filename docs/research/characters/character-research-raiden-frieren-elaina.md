## 一、雷电将军（Raiden Shogun / 雷電将軍 / 雷電將軍）

### 角色信息
- **角色名**：雷电将军（中文）/ Raiden Shogun（英文）/ 雷電将軍（日文）；真名即"雷电影 / Ei / 巴尔泽布（Beelzebul）"，雷电将军是在其"人偶之身"上运行统治的指挥官。
- **原作与世界观**：手机/PC 游戏 **《原神 Genshin Impact》**（miHoYo/米哈游）。
  - 世界观类型：**奇幻（提瓦特大陆）**，带有神明信仰与元素魔法体系。
  - 时代背景：幻想中世纪后期（稻妻为和风化岛国文明；武士、神社、幕府、"雷电/鸣神"信仰），人类科技整体为近乎前现代的水平（无现代电力/霓虹都市）。
  - 所属地区：**稻妻（Inazuma）**，雷之国；神之治世、永恒（Eternity）理念。

### 外貌特征（可作提示词）
- **发色**：深紫色（紫罗兰/紫罗兰-黑），长发。
- **发型**：单边长马尾辫，从头顶引出、垂于胸前一侧；前有长刘海与鬓发，整体利落而带和风。
- **瞳色**：紫红色 / 深紫色（偏紫）眼瞳，目光威严。
- **标志物**：额头有浅紫色"雷之巴纹/阴刻纹"装饰；眼部常绘有向下渐变黑影（威严/阴影描绘）；左胸近心位置有雷之瞳记号的深条纹装饰；无兽耳/无角（非兽类神）。
- **补充**：常以背对雷暴、环绕紫电的"神相"登场，身周有紫电雷光粒子。

### 服装（标志性服装 · Danbooru 词条）
- **和服式"振袖铠"**：主体为白底+樱色/紫/深蓝配色的和服套装，外披带兜帽的白色羽织（"万雷般的羽织"），下摆渐变为紫→深的渐变裙摆。
- 腰间束紫色宽带（腰带），胸前有深紫色雷纹装饰。
- 无袖内里+半露锁骨领口的和风打褂；整体色系：**白、魔（magenta）樱粉、紫、深蓝灰**。
- 常配一把太刀（梦想一心），刀身缠绕紫电。
- 整体是"雷神主君"式的威严和服+甲胄视觉，不是轻便战斗服。

### 性格气质（影响场景 mood）
- 威严、沉静、寡言、近乎无感情的"人偶君主"感；贯彻"永恒"的秩序与肃穆。
- 战斗时凌厉、雷电奔涌；日常则清冷、克制、居高临下。
- 适配 mood：**庄严肃穆 / 静谧威严 / 雷雨压迫 / 王座孤高**。

### 原作典型场景（3-5 个）
1. **稻妻天守阁（Tenshukaku）**：雷电将军的宫殿/猎雷处，暗红与紫的幕府内廷、屏风、神龛。
2. **雷暴之夜 / 万雷具现**：天空紫电闪鸣、大雨、神社鸟居与雷电交加（"御建鸣神主尊大御所大人"降神相）。
3. **神社 / 鸣神大社**：雷元素神龛、红白巫女元素、樱花与紫电并存的圣境。
4. **雷电将军的战斗空间**：刀光与紫电横空、拔刀斩"梦想一心"。
5. **稻妻城/幕府街景（雨夜）**：和风城镇、灯笼、带湿气的石板路。

### 角色专属词条建议（Danbooru 风格英文标签）
- **外貌（3-5）**：`single_braid`, `long_hair`, `purple_hair`, `purple_eyes`, `lightning_motif`（额印/雷纹）
- **服装（3-5）**：`japanese_clothes`, `kimono`, `hakama`, `jacket`, `dark_background`（和服+羽织外衣）
- **道具（2-3）**：`katana`, `sword`, `lightning` / `glowing`
- **氛围（2-3）**：`dark_rem`, `storm`, `night`（雷雨夜肃穆感）

> 注：原神角色官方立绘/建模标注常含 `genshin impact`、`raiden shogun` 词条；加入 Danbooru 首页 tag 可锁定辨识度。

### 适合的场景类型（2-4 类）
1. **和风奇幻**（天守阁/神社/幕府内廷）
2. **雷雨之夜 / 暴风雨**（紫电、大雨、压迫感）
3. **神社夜景 / 圣境**（红白巫女+樱+紫电）

### 明确不适合的场景类型
- **现代校园 / 都市霓虹夜景**（奇幻神君+和风与霓虹现代设定冲突）。
- 不适合**现代工业/机械前卫**场景（打破提瓦特近前现代世界观）。

## 二、芙莉莲（Frieren / フリーレン / 葬送的芙莉莲）

### 角色信息
- **角色名**：芙莉莲（中文）/ Frieren（英文）/ フリーレン（日文）。
- **原作与世界观**：漫画/动画 **《葬送的芙莉莲 / Frieren: Beyond Journey's End / 葬送のフリーレン》**（山田钟人原作，阿部司作画）。
  - 世界观类型：**传统奇幻（中世纪欧洲风）**。
  - 时代背景：勇者队伍讨伐魔王后的"和平过渡期"；魔法使、勇者、精灵、人类混杂的古典冒险世界。
  - 身份：**精灵族长寿魔法使**，因宰葬众多魔族而被称为"葬送的芙莉莲"。

### 外貌特征（可作提示词）
- **发色**：银白 / 蛋白石白（silvery-white / white），极长（近乎腿部）。
- **发型**：标志性 **双马尾**（两侧长辫/低双马尾），发尾自然散落；刘海齐整。
- **瞳色**：**紫 / 淡紫色（偏粉紫）眼瞳**（设定为紫色系），神情平和。
- **标志物**：**精灵长耳（pointed elf ears / elven ears）**；因是精灵，外表年轻，实际寿命绵长。
- **补充**：表情常带着慵懒、温和的"心不在焉"感，眼睛呈低垂的无辜大眼。

### 服装（标志性服装 · Danbooru 词条）
- **白色系魔导斗篷**：上半身为白色/米白短袍+同色披风（无兜帽），内衬高领与束带。
- 下半身常穿 **浅色裙装+白色过膝袜/靴**；整体为白、奶油白、绿/水色点缀的温和配色。
- 手部戴魔法手套（指节有装饰）；腰间或袖上有小配件。
- 视觉上"清洁、淡雅、带一丝魔法使的飘逸"，不是重甲/浓艳。

### 性格气质（影响场景 mood）
- 温和、缄默、理性、带疏离感的"长寿者"气质；对时间流逝淡然，怀念勇者队伍。
- 情绪内敛，偶尔慵懒或陷入回忆。
- 适配 mood：**静谧怀念 / 旅途冥想 / 温柔感伤 / 清淡治愈**。

### 原作典型场景（3-5 个）
1. **旅途中 / 旷野小径**：披风在风吹中飘动，一人独行或与同伴并肩。
2. **墓地 / 勇者辛美尔之墓**：白花、十字墓、念旧怀人之景。
3. **魔法书 / 魔法研究**：摊开魔法书、魔法闪光、古代遗迹魔法阵。
4. **精灵聚居地 / 湖畔神殿**：精灵故乡、森林与湖泊的静谧。
5. **与魔族/怪物的战斗空间**：优雅持杖、元素/魔发光效（较少、克制）。

### 角色专属词条建议（Danbooru 风格英文标签）
- **外貌（3-5）**：`white_hair`, `long_hair`, `double_hair bun / twin braids`（双马尾）, `purple_eyes`, `elf_ears`
- **服装（3-5）**：`cape`, `robe`, `white_clothes`, `cloak`, `dress`
- **道具（2-3）**：`staff / magic wand`, `magic`, `book`
- **氛围（2-3）**：`daylight / outdoor`, `journey / travel`, `nostalgia`（旅途怀念感）

> 注：Danbooru 首页词条为 `frieren (sousou no frieren)`；加 `sousou no frieren` 可锁定作品。

### 适合的场景类型（2-4 类）
1. **魔法图书馆 / 古籍藏书**（魔法书、烛火、古卷）
2. **中世纪欧洲旷野旅途**（黄昏、风吹披风）
3. **雪原 / 森林静谧**（长寿者独行感）
4. **墓地 / 樱花退藏之地**（回忆、白色调）

### 明确不适合的场景类型
- **现代都市霓虹 / 赛博机械**（古典魔法使设定冲突）。
- **泳池派对 / 现代校园日常**（打破古朴旅途世界观）。

## 三、伊蕾娜（Elaina / イレイナ / 魔女之旅）

### 角色信息
- **角色名**：伊蕾娜（中文）/ Elaina（英文）/ イレイナ（日文）。
- **原作与世界观**：轻小说/动画 **《魔女之旅 / Majo no Tabitabi》**（白石定规）。
  - 世界观类型：**魔法奇幻（魔法使/魔女世界）**。
  - 时代背景：魔女、魔法、飞行扫帚的旅居世界；以"旅行见闻"为主题的单元式世界观（许多风格各异的地区/国家）。
  - 身份：**天才魔女 "灰之魔女"（The Grey Witch）**，为旅行而四处游历。

### 外貌特征（可作提示词）
- **发色**：**灰银色 / 银白灰（ash gray / gray-silver）**，长发。
- **发型**：中长直发，后缘略翘（波波头偏中长），额头有齐刘海。
- **瞳色**：**紫色 / 蓝色眼瞳**（不同作画/看板存在紫眼或蓝眼差异，均被广泛采用；以**紫色眼眸**为最常见设定）。
- **标志物**：黑色魔女帽（尖顶、带金色/暗色饰）+ 魔法杖/飞行扫帚；常戴黑色魔女帽出现在各大插画与 Danbooru 看板。
- **补充**：气质带"文学少女"式的自恋/毒舌，但容颜清丽。

### 服装（标志性服装 · Danbooru 词条）
- **黑色魔女装**：黑色露肩连衣裙 + 黑靴 + **黑色尖顶魔女帽**。
- 配饰：领结/蝴蝶结、披风或短斗篷可选；通体以黑为主（偶尔有紫/蓝点缀）。
- 造型与"灰之魔女"名号呼应，整体是标准"西方魔女"形象（宽檐尖帽+黑裙+扫帚）。

### 性格气质（影响场景 mood）
- 聪慧、自信、略带自恋与毒舌的"傲娇文学少女"；表面优雅实则狡猾（"屑魔女"昵称）。
- 在旅途中见识人性百态，时而温情、时而辛辣。
- 适配 mood：**轻盈旅行 / 优雅俏皮 / 灵异见闻 / 乐观冒险**。

### 原作典型场景（3-5 个）
1. **飞行扫帚 / 云端飞行**：跨坐扫帚、长裙与帽在风中、天空远景。
2. **各国旅行见闻**：拜访不同国家/城市的街景、市集、地标。
3. **咖啡馆 / 书店小憩**：旅途间歇的安静落脚点，喝咖啡看书。
4. **夜间魔法世界**：星空、烛火、魔法书页翻动的灵异之夜。
5. **与旅途中人物的邂逅**：村庄、酒馆、路边摊，单元故事舞台。

### 角色专属词条建议（Danbooru 风格英文标签）
- **外貌（3-5）**：`gray_hair`, `long_hair`, `purple_eyes`（或 `blue_eyes`）, `blush`, `middle_hair`（中长）
- **服装（3-5）**：`witch_hat`, `witch`, `black_dress`, `single_earring`（可选）, `cape`
- **道具（2-3）**：`broom`, `staff`, `flying`（飞行）
- **氛围（2-3）**：`travel / journey`, `outdoors`, `fantasy`（魔女旅途感）

> 注：Danbooru 首页词条为 `elaina (majo no tabitabi)`；加 `majo no tabitabi` 锁定作品。

### 适合的场景类型（2-4 类）
1. **魔法旅行 / 云端飞行**（扫帚、天空、白云）
2. **夜间魔法 / 灵异见闻**（星空、烛光、书页）
3. **书店 / 咖啡馆小憩**（旅途幸福感）
4. **异国小镇市集**（单元旅行地标）

### 明确不适合的场景类型
- **现代机械工业区 / 赛博霓虹前卫**（标准西方魔女+古典地图旅行设定冲突）。
