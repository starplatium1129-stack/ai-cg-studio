## 实现与本次验证边界

- 后续交互细节修复见 [全站细节审查](archive/audits/interaction-detail-polish-2026-09-12.md)：菜单/搜索/灯箱焦点、角色选中配色、录音松开、分镜反馈与照片叠字；不把这些 UI 验证计作真实模型交付。
- 当前源码为 Vue 3 / Vite / TypeScript / Pinia 前端、Express 网关、Tauri 2 桌面壳，业务覆盖角色/场景、绘图工作台、作品册、聊天/语音、Live2D 和视频分镜。
- SD、Anima、Krea 2 有独立请求与编译路径；参数以当前配置和请求为准。办公机没有模型出图环境，本次没有修改提示词/分级/场景源数据，也没有验证生成画质。
- 深浅主题、响应式界面与页面懒加载已有实现。本次门禁覆盖令牌对比度、动画、样式、类型、测试与包体；浏览器结果和人工查看范围单独记录在审计中。
- 本次 `gate:full` 在显式 `AICS_REFERENCE_AUDIT_MODE=structure` 下通过，包括 475 项 Node 单测、25 组契约和生产构建；此模式仅验证参考索引结构，不代表外部参考文件可用。
- 修复前浏览器全套为 456 过 / 19 失败；旧契约、样张夹具及首屏适配已调整，修复后结果以 1.7.1 发布说明为准，原始失败记录保留。
- 本轮桌面构建环境 doctor 就绪。依赖零已知漏洞与 6 项纯 Rust 节拍测试属于修复前独立审计，未在本轮重复执行；均不代表安装迁移、Cubism overlay、真实设备或闲置功耗验收。
- 审计 A01–A05 已按行为回归修复：聊天清除/写入失败/流式合并、远程自配目标边界、绘画工具虚报完成。绘画工具目前只准备草稿，真实任务接线尚未完成。
