# 场景维护工作台重构 · 1.5.7

基线为 9cf747b5。主工作区同时存在另一批角色数据与主题改动，本轮已隔离到独立工作树，只包含场景维护 UI 与本机部署辅助的修改。

## 查看与维护

| Before | After | Why |
| --- | --- | --- |
| 多列宽表格，故事只显示一小段 | 记录列表与完整详情并排 | 连续检查内容时不必反复开关编辑弹窗 |
| 每行都放编辑、复制、下架 | 当前记录的操作集中于详情区 | 明确操作对象，降低误点 |
| 场景和蓝图使用不同浏览布局 | 共用搜索、角色/分类/分级筛选与分页 | 维护两类数据时保持相同操作习惯 |
| 桌面只读模式难以查看完整内容 | 只读仍能查看详情、提示词、复制 JSON 和进入创作台 | 不改变应用包写入限制，也能完整检查场景 |
| 大标题占用工作区 | 紧凑标题与独立滚动的列表、详情 | 适配 1440、1280、1024 宽度；窄窗口减少重复状态装饰 |

- 搜索覆盖 ID、标题、角色名、故事、标签与提示词。
- 场景库支持待审核与信息待补的快捷筛选；信息待补是浏览提示，不替代服务端内容校验。
- 切换场景/蓝图库保留各自筛选；列表支持上下方向键、Home/End。
- 翻页、筛选、记录删除后，选中项与详情保持一致；切换记录回到详情开头。
- 编辑沿用现有弹窗和领域逻辑；弹窗保存只更新草稿，点击“保存到项目”才写盘。脏态离开确认与保存失败反馈保留。
- JSON 复制基于完整原始记录，包括未在面板展示的扩展字段；提示词为原文展示，不重新组装。远程成人记录不开放详情与复制。

## 本机更新

沿用 deploy-desktop.bat 唯一入口。新增可选 `-UseInstaller -QuietInstall`：用户确认 UAC 后自动完成安装、清理缓存、校验依赖并重启。安装器非零退出会失败，日志追加至 runtime/desktop-deploy-last.log。

安装后需要核对已安装 EXE 版本、网关状态与实际场景维护窗口；不能仅根据构建成功或启动 UAC 判断已完成安装。
