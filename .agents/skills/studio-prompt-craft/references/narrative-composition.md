# CG 与人物壁纸：画面设计与编译保真

适用于人物参与环境的 CG，以及单人物立绘／特写壁纸。先区分创作目标；沿用入口的身份、衣装、分级和交付约束，不把本参考升级为所有图像的固定构图模板。

- 叙事 CG 重视事件与人物环境关系；人物壁纸重视身份、轮廓、表情、衣装和桌面留白。简单背景可构成完整壁纸，全身完整与有意特写裁切分别评价。4K 150% 桌面缩放不改变最终壁纸的 3840×2160 目标，生成尺寸仍以实际工作流支持为准。

- 叙事 CG 先明确可见事件、焦点、人物与关键物件的位置／接触，以及共享光源，再组织引擎输入。补充细节应服务原始意图，不能为丰富度擅自增添人物或改衣装。
- 空间层次和细节数量按画面需要决定；特写不强塞远景，环境叙事不机械加极浅景深，远景人物可以通过轮廓或颜色成为焦点。没有固定主体比例或“越多越好”的物件配额。
- Anima 按 profile 保持标签／精确词，再用有效描述通道写关系；Krea 按项目契约写连贯 prose。两者共享画面意图，不共享一份机械模板或参数。
- 最终编译检查要特别看：通用 Anima 的显式 animaCaption 与自动短语筛选；热门分支的 sceneProse 及自动尾句；left／right 到 off-center 的映射；Krea 自动身份句、风格与单数代词。它们是已观察到的实现行为，不能假设原文原样送达，也不能未经出图断言一定损害画质。
- 当前本地 Krea 使用自定义编码器／增强链路；按实际 workflow 记录参数，不能把托管扩写、风格参考或官方裸 Turbo 示例当成本地能力。长短文本也不等价于 creativity 参数。
- 官方事实、项目行为、待实测建议分开。写作规范可立即用于草稿与审核，具体短语效果只有经过对应 checkpoint 的真实对照才升级为默认经验。

按需阅读：

- [日常规范与原创候选案例](../../../../docs/guides/prompts/narrative-cg-prompt-standard.md)：画面简报、双引擎表达、场景／特写／多人边界与评审。
- [单人物立绘与特写壁纸](../../../../docs/guides/prompts/character-wallpaper-prompt-standard.md)：独立目标、横幅留白、全身／面部裁切和双引擎候选；不强制背景叙事。
- [手机竖屏壁纸](../../../../docs/guides/prompts/mobile-wallpaper-prompt-standard.md)：iPhone 17 Pro 的 1206×2622 交付基准、通用长屏比例、锁屏／主屏遮挡；不将桌面横图直接裁成竖屏。
- [完整研究及来源](../../../../docs/research/prompts/anima-krea2-narrative-cg-research-2026-09-12.md)：官方证据、旧规则冲突、源码风险和适用范围。
- [未执行的对照计划](../../../../docs/research/prompts/anima-krea2-narrative-eval-plan.json)：小样预算、固定 seeds、参数冻结和记录字段；不是可直接运行的生产场景清单。

成功输出不等于通过审核；保留失败图、平局和关键约束失败。不能声称规范保证每个 seed 都惊艳，也不能用文档案例代替生产 Token／真实画面验收。
